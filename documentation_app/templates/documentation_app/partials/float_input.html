Float Input

File: GalaxyFloatInput.js
Tag: galaxy-float-input
Extends: GalaxyNumberInputBase
A custom input element for floating-point numbers. It is a thin subclass of GalaxyNumberInputBase -- it only sets its own type to "float" so values are cast and validated as floats -- so all of its attributes and methods are inherited from Number Input Base and Input Base.

See GalaxyNumberInputBase. Defaults to "Any", so any number of decimal places is accepted unless a specific step is set.

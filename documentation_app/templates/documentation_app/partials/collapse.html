Collapse

File: GalaxyCollapse.js
Tag: galaxy-collapse
Extends: GalaxyHTMLComponentBase
A panel that shows and hides its content. An element with slot="heading" is the clickable heading; everything else inside the element -- any HTML, Galaxy components and form fields included -- is the collapsible body. The heading is a real button, so Tab, Enter, and Space work, and it reports aria-expanded. While closed, the body is inert, so the keyboard cannot reach content that is not visible. Opening and closing animate the height unless the user prefers reduced motion.

Closing a panel also closes anything inside it that floats outside it -- an open Select dropdown, a date picker's popup -- by calling close_floating_content() on every element inside that has one, including fields a form has moved into its shadow root. And when a Form fails validation, it calls reveal() on the panels around its first invalid field, so a required field in a closed panel is opened and scrolled to rather than blocking submit invisibly.

Nothing is stored: the open state lives only in the open attribute, so a new page starts from its markup. A page that wants the state remembered keeps it itself, e.g. from the toggle event. Panels nest, and an accordion (one open at a time) is a few lines of page script on the bubbling toggle event.

Attributes

open

Observed: true
Default: false
Boolean. Shows the body. Present in markup, the panel starts open without a toggle event.

Methods

expand() / collapse() / toggle()

Open, close, or flip the panel. Each changes open, which dispatches toggle when the state actually changes.

reveal()

Opens the panel so something inside it can be seen. The shared hook Form.reveal_element() calls on every ancestor of an invalid field.

close_floating_content()

Calls close_floating_content() on every element inside the panel that has one, through nested shadow roots. Runs whenever the panel closes.

Getters / Setters

open

get/set: Mirrors the open attribute. Reading it right after setting it gives the new state; aria-expanded, inert, and the toggle event follow a microtask later, on the attribute-changed reaction.

Events

toggle

Dispatched, bubbling, whenever the panel opens or closes -- from a click or from code -- with event.detail.open. Setting the state it already has dispatches nothing. Because it bubbles, check event.target to tell a nested panel's toggle from the panel's own.

            // An accordion: opening one panel closes the others
            container.addEventListener("toggle", (event) => {
                if (event.detail.open) {
                    for (let panel of container.querySelectorAll(":scope > galaxy-collapse")) {
                        if (panel !== event.target) {
                            panel.collapse();
                        }
                    }
                }
            });

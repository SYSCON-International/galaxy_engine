Engine

File: GalaxyEngine.js
Tag: N/A
Extends: N/A
The Engine class is entry to the Galaxy Engine framework. It initializes the engine by loading the Components Loader, the State Manager, and utils and makes them available in the window.

Attributes

Observed: false
Default: false

Methods

initialize

Initializes the GalaxyEngine framework. This method is called when the script is loaded and starts the engine by loading the components, state manager, and utils. The State Manager can be accessed via window.galaxy_state_manager and the Utils via window.galaxy_utils.

handle_body_click(event)

Handles click events on the body to trigger modals and other interactions. The trigger is found through event.composedPath(), so a galaxy-modal-id element inside a shadow root - a Form's fields live in one - still opens its modal.

handle_modal(event, closest_galaxy_modal_id_element)

Handles the modal interaction when an element with the attribute galaxy-modal-id is clicked. If the element has the attribute, it will open the modal with the ID specified in the attribute, found by id (any id works, including one that is not a valid CSS identifier) in the document or inside a shadow root, through the component registry (see find_component()).

Getters / Setters

GALAXY_COMPONENT_TAG_NAMES

While technically a constant it can be used as a getter to retrieve the tag names of the Galaxy Engine components.

get: Component Tag Names

engine_css

get: The engine-wide CSS added at the start of the document head: the 12-column grid variables and the default color palette. Override any variable by redeclaring it in your own stylesheet. Besides the colors, it includes:
  • --dropdown-background, --dropdown-shadow, --dropdown-option-hover and --dropdown-option-highlight - the lists of a Select, Multi-Select and Combo Box, and a date picker's popup.
  • --notifications-top and --notifications-right - where notifications appear (default 10px each).
  • --input-background and --input-readonly-background - an input field's background, and a readonly field's.
  • --input-disabled-text, --input-disabled-label, --required-marker - a disabled field's text and label, and a required field's asterisk.
  • --focus-ring and --invalid-ring - the glow around a focused field (and the table's sort buttons and date popup's buttons) and around an invalid field.
  • --text-muted, --notification-background, --notification-border, --notification-divider - a notification's footer text, background, border, and the line under its header.
Each component falls back to the same default when the engine's palette is not loaded.

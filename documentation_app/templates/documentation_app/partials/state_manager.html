State Manager

File: GalaxyStateManager.js
Tag: N/A
Extends: N/A
The GalaxyStateManager is a class that manages the state of the Galaxy Engine. It provides methods to get and set the current state, as well as to reset the state to its initial values. This class is essential for maintaining the overall state of the Galaxy Engine, allowing for easy access and modification of the engine's state throughout the application.

Attributes

Observed: false
Default: false

Methods

create_proxy(object)

Creates a proxy for the given object. This proxy will intercept property access and method calls, allowing for custom behavior.

trigger_dom_update(property, value)

Triggers a DOM update for the specified property with the given value. This method is used to ensure that any changes to the state are reflected in the UI by updating the values of the relevant DOM elements and triggering a change event.

add_property(property, value)

Adds a property to the state manager with the specified value. This allows for dynamic addition of properties to the state.

remove_property(property)

Removes a property from the state manager. This is useful for cleaning up properties that are no longer needed.

update_property(property, value)

Updates the value of an existing property in the state manager. This allows for modification of properties without needing to remove and re-add them.

update_all_bound_elements()

Updates all elements bound to the state manager. This ensures that any changes to the state are reflected in the UI by triggering a DOM update for all bound elements.

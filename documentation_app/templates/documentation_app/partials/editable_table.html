Editable Table

File: GalaxyEditableTable.js
Tag: galaxy-editable-table
Extends: GalaxyTable
A Table whose cells are edited in place. Columns, rows, sorting (client-sort), the empty state, and column render functions work as on the Table; the light-DOM <table> source does not, since its cloned markup cannot be edited.

Each column's type picks the Galaxy input its cells are edited with, drawn compact and plain: a value reads as ordinary table text, and the field's border appears only when the cell is hovered or focused. A multi-select cell uses its dropdown, so its row stays one line high. Each row is open or locked, carried in its data as _state; a locked row's cells are disabled and it cannot be removed. An actions column holds each row's lock toggle and remove button, and an "Add Row" button sits below the table. Cells are marked with an error from their own validation or from code. User actions dispatch events; the matching methods do the same from code without them. Editing a cell never re-renders the table, so the cell being typed in keeps its focus and caret; locking re-renders only that row.

It is form-associated: with a name, it submits its rows as one JSON value, and a Form that finds it invalid focuses its first invalid cell. Its cell editors live in its shadow root and are not submitted individually.

Column Options

type

"text" (the default), "combo-box", "integer", "float", "select", "multi-select", "checkbox", "date", "time", or "datetime" -- edited with the matching Galaxy input. Values are kept in their type: a number or null when empty, a boolean, a select's single value (null for none), a multi-select's array, and an ISO string or null for dates.

editable

false shows the column read-only, as the Table shows it (including render). Defaults to editable.

options / suggestions / required / min / max / step / maxlength / placeholder

Passed to each cell's editor: options (the select types' option data), suggestions (a "combo-box" column's suggestions), required, min, max, step, and placeholder. maxlength is checked by the table.

default

The value a row added with "Add Row" (or add_row()) starts with for this column.

Attributes

readonly

Observed: true
Default: false
Boolean. Disables every cell and hides the add, remove, and lock controls.

hide-add / hide-remove / hide-lock

Observed: true
Default: false
Booleans hiding the "Add Row" button, the remove buttons, and the lock toggles. With both hide-remove and hide-lock, the actions column goes away. Rows keep their state when the lock toggle is hidden; it just cannot be changed from the table.

max-body-height

Inherited from Table: the body scrolls under a sticky header.

name

Observed: true
Default: null
The field name the rows are submitted under, as one JSON array (each row's values plus _state). Form reset restores the rows as they were last set from code.

Methods

add_row(row_data = {}) / remove_row(row_id) / lock_row(row_id) / unlock_row(row_id)

Add a row (filling columns it leaves out with their default; returns its id), remove one (locked or not; returns its data), or change a row's state. None dispatches an event -- events are for user actions. In a paged table (page-size), adding a row moves to the page it lands on.

get_row(row_id) / is_row_locked(row_id)

A copy of a row's data with _state (or null), and whether it is locked. row_ids lists every row's id in order.

set_cell_error(row_id, key, message) / clear_cell_error(row_id, key) / clear_cell_errors()

Mark a cell with an error from code -- typically one the server reported -- or clear it. A marked cell has a red outline, aria-invalid, and the message as its tooltip (shown even while hovering its editor) and aria-description, and makes the table invalid until that cell is edited or the mark is cleared.

validate()

Validates every editable cell of every open row -- each editor's own validation, then maxlength, with any error set from code taking precedence -- marks the invalid cells, and sets the table's validity, anchored to the first invalid cell. Locked rows, and every cell of a readonly (or fieldset-disabled) table, are not checked. Rows on other pages of a paged table have no editors, so their values are checked the way the editor would, with its messages: required; for an integer or float column, text that is not a number, a fraction in an integer column, and min/max; for a date, time or datetime column, a value that is not one; and maxlength. So a cell is valid or not whichever page it is on. Returns a boolean.

focus_first_invalid()

Scrolls the first marked cell into view within the table and focuses it, moving first to its page when it is on another one. A Form calls it when the table is its first invalid field.

render_row(row_id)

Replaces one rendered row, using the Table's create_row_element() hook, without touching the others.

Getters / Setters

rows

get: Copies of the rows in their order, each with _state.
set: Replaces every row (an array or a JSON string); _state: "locked" starts a row locked. Each row gets a new id. Dispatches no events. The table copies the rows, so edits never change the objects passed in. A value that cannot be copied -- a function, a DOM element -- is kept as the same reference (see clone_value()).

readonly / hide_add / hide_remove / hide_lock / name

get/set: Mirror the matching attributes.

Events

row_add / row_change / row_remove / row_lock

Bubbling events for user actions: "Add Row" ({row_id, row}), a cell edit, as the value changes ({row_id, row, key, value, old_value}), a remove button ({row_id, row}), and a lock toggle ({row_id, row, locked}).

Example


            
        

            let table = document.getElementById('machine_setup');

            table.columns = [
                {key: "name", label: "Machine", type: "text", required: true},
                {key: "cycle_time", label: "Cycle Time (s)", type: "integer", min: 0, default: 30},
                {key: "is_enabled", label: "Enabled", type: "checkbox", default: true},
            ];
            table.rows = [{name: "Press 1", cycle_time: 45, is_enabled: true, _state: "locked"}];

            table.addEventListener('row_change', (event) => console.warn(event.detail.key, event.detail.value));
            table.set_cell_error(table.row_ids[0], 'name', 'Already used by another machine');

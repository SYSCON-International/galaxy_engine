Checkbox

File: GalaxyCheckbox.js
Tag: galaxy-checkbox
Extends: GalaxyInputBase
A boolean input, drawn as a checkbox or, with switch, as a toggle switch. Its value is a real boolean mirroring checked, and it submits "true" or "false" with its form -- including when unchecked, unlike a native checkbox, which submits nothing then. The label sits beside the box and toggles it when clicked. A user toggle dispatches change on the element; setting checked or value from code does not. Everything else -- disabled, label, name, required, property-name, label-layout -- comes from Input Base, with the differences noted below.

With tri-state, the mixed state becomes a third value the user can pick: clicks cycle unchecked, indeterminate, checked, unchecked -- so three clicks from indeterminate return to it -- and while indeterminate value is null and the form submits "", a nullable boolean.

Attributes

checked

Observed: true
Default: false
Boolean. The checked state, and the source of value. Its state when the element is created is what a form reset restores.

indeterminate

Observed: true
Default: false
Boolean. Shows the mixed state (e.g. a "select all" box over a partial selection). Without tri-state it is purely visual -- value still reports checked -- and removed when the user next toggles the box. With tri-state it is the third value: value is null.

switch

Observed: true
Default: false
Boolean. Draws the box as a toggle switch and announces it to assistive technology as a switch (role="switch").

tri-state

Observed: true
Default: false
Boolean. Puts the indeterminate state in the click cycle: unchecked, indeterminate, checked, unchecked. While indeterminate, value is null, the form submits "", the state manager gets null, and a required box is invalid. Form reset also restores the initial indeterminate state. Works with switch, which shows indeterminate with the knob centered.

value

Observed: true
Default: null
Unlike a native checkbox, not the submitted string: written in markup it sets checked, where "true", "1", "on", and "yes" (any case) mean checked. With tri-state, "", "null", "indeterminate", and "mixed" mean indeterminate. Prefer checked / indeterminate.

readonly

Observed: true
Default: false
Blocks toggling by mouse, keyboard, or label while still submitting the current value. A native checkbox ignores readonly; this one does not.

required

Observed: true
Default: false
The box must be checked. The error message is "Please check this box."

Methods

parse_boolean(value)

Converts a boolean-like value to a boolean: true, a non-zero number, or "true", "1", "on", or "yes" in any case. Everything else is false.

parse_tri_state(value)

Like parse_boolean, but returns null for null, undefined, and "", "null", "indeterminate", or "mixed" in any case. Used for value in tri-state mode.

get_next_tri_state_value()

The value a click moves to in tri-state mode: false to null, null to true, true to false.

update_form_value()

Submits "true"/"false" (or "" while indeterminate in tri-state mode) and mirrors the value to the state manager under property-name. Called on every change.

Getters / Setters

value

get: The checked state as a boolean -- or null while indeterminate in tri-state mode.
set: Checks or unchecks the box from a boolean or a boolean-like string (see parse_boolean); in tri-state mode a null-like value sets indeterminate (see parse_tri_state). Does not dispatch change.

checked / indeterminate / switch / tri_state

get/set: Mirror the matching boolean attributes.

Events

change

Fired on the element, bubbling, when the user toggles the box. Read the new state from event.target.value.

Example


            
            
            
            
        

            let checkbox = document.querySelector('galaxy-checkbox[name="is_enabled"]');

            checkbox.addEventListener('change', (event) => console.warn(event.target.value)); // true or false
            checkbox.value = false; // unchecks it, without a change event

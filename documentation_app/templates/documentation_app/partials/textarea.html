Textarea

File: GalaxyTextarea.js
Tag: galaxy-textarea
Extends: GalaxyInputBase
A multi-line text input -- comments, notes, or a field samples are scanned into one per line. rows sets its visible height, maxlength caps its length, and auto-grow makes it grow to fit its content instead of scrolling. Everything else -- value, label, name, required, readonly, disabled, placeholder, property-name binding, form submission -- works as on any Input Base input. It has its own textarea styles matching the other inputs, with a vertical resize handle; a readonly textarea can still be scrolled and its text selected.

Attributes

rows

Observed: true
Default: 3
The number of visible lines -- the height, or the minimum height with auto-grow. A missing or invalid value falls back to 3.

maxlength

Observed: true
Default: null (no limit)
The maximum number of characters. The browser stops the user typing past it; a longer value set from code or the state manager is a validation error ("Please enter no more than N characters."), required or not.

auto-grow

Observed: true
Default: false
Boolean. Grows the textarea to fit its content, from a minimum of rows, instead of scrolling; the resize handle is hidden. It refits as the user types, when the value is set from code or state, and when the width changes (narrower text wraps onto more lines).

Methods

update_auto_grow_height()

Fits an auto-growing textarea's height to its content, never shorter than rows. Does nothing without auto-grow. Call it after changing something that affects wrapping that the textarea cannot see, such as its font.

get_validation_errors(value)

Reports a value longer than maxlength. See Input Base.

Getters / Setters

rows / maxlength / auto_grow

get/set: Mirror the matching attributes. rows and maxlength return numbers; setting null removes the attribute.

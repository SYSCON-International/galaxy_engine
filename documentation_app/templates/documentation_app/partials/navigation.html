File: GalaxyNav.js
Tag: galaxy-button
Extends: GalaxyComponentBase
The galaxy-nav is a customizable navigation component. It allows for the easy creation of a horizontal or vertical navigation bar/menu with customizable theme, dropdown, multi-column dropdown, sections, brand, headers, and icon support.

Attributes

theme

Observed: true
Default: light
Sets the theme for the navigation. Comes with 2 default themes, light and dark, but the user can pass in their own custom theme as well. Note: This can be set in the config.

layout

Observed: true
Default: horizontal
Sets the layout for the navigation. Available options are, horizontal and vertical. Note: This can be set in the config.

config

Observed: true
Default: null
Takes a JSON string to be used as the definition for the navigation. The config can also handle setting the layout and theme as well.

Methods

add_theme_css()

Adds the theme CSS to the document. This function dynamically generates CSS variables based on the theme settings and applies them to the document root. It also determines the position of the navigation based on its layout and viewport dimensions.

async build_nav_sections()

Builds the navigation sections based on the config.

create_nav_button(item)

Creates a navigation button element based on the passed in item.

async build_nav_item(item)

Builds a navigation item, including handling of multi-column dropdowns and nested children.

Date Picker

File: GalaxyDatePicker.js
Tag: galaxy-date-picker
Extends: GalaxyDatetimePickerBase
A date-only picker. A thin subclass of Datetime Picker Base that only passes "date" as the mode -- its full API (attributes, popup behavior, value shapes) is documented there. The time-format attribute has no effect in this mode, since there's no time portion.

Attributes

None

No attributes of its own -- see Datetime Picker Base for label, layout, and value.

Methods

None

No methods of its own -- see Datetime Picker Base.

Getters / Setters

None

No getters/setters of its own -- see Datetime Picker Base.

Observers

None

No observers of its own -- see Datetime Picker Base.

            let start_date = document.querySelector('#start_date');

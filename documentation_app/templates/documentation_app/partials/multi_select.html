Multi-Select

File: GalaxyMultiSelect.js
Tag: galaxy-multi-select
Extends: GalaxySelectBase
A custom multi-select element that extends the GalaxySelectBase class. It allows users to select multiple options from a dropdown list, and stores the selection as a JSON array string in value (e.g. '["option1","option2"]').

By default its list always shows in the page, about seven options tall, and its field is only a search box (hidden without search-enabled). With dropdown it works like a Select instead: the closed field shows the selected options' texts joined with commas, and clicking it (or ArrowDown, Enter, or Space) opens the list as a floating popover. Choosing options leaves it open; clicking outside or Escape closes it.

Attributes

dropdown

Observed: true
Default: false
Boolean. Opens the options in a floating dropdown from the field instead of always showing them in the page. Toggling it switches between the two at any time, closing the dropdown. See Select Base for options-data, open, search-enabled, collapsible-groups, placeholder, and options-size.

Methods

option_on_click(option_element, option_icons_container_element, option_data)

Overrides GalaxySelectBase's abstract stub to implement multi-select toggling: if the clicked option is already selected it's removed, otherwise it's added, and value is updated to the new JSON array of selected values. Unlike Select, clicking an option never closes the dropdown, so multiple options can be picked in one open session.

Getters / Setters

dropdown

get: Gets whether the options open in a dropdown.
set: Sets whether the options open in a dropdown.

input_on_click()

With dropdown, toggles the dropdown open, clearing the field for searching when search-enabled. Does nothing otherwise.

Observers

handle_observed_dropdown(new_value)

Handles changes to the dropdown attribute.

Example


            
            
        

            let multi_select = document.querySelector('galaxy-multi-select');

            multi_select.options = [
                { value: 'option1', text: 'Option 1' },
                { value: 'option2', text: 'Option 2' },
                { value: 'option3', text: 'Option 3' }
            ];

            multi_select.value = '["option1", "option3"]'; // Pre-select two options

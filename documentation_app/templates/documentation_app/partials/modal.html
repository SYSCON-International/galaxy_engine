Modal

File: GalaxyModal.js
Tag: galaxy-modal
Extends: GalaxyComponentBase
The GalaxyModal component is a modal dialog that can be used to display content in a popup window. It extends the GalaxyComponentBase class and provides additional functionality for managing modal dialogs.

Attributes

has-ok-confirm

Observed: false
Default: false
Indicates whether the modal will have confirmation on the OK button.

has-cancel-confirm

Observed: false
Default: false
Indicates whether the modal will have confirmation on the Cancel button.

quick-close

Observed: false
Default: false
Indicates whether the modal can be closed quickly using the Escape key or by clicking outside the modal.

open

Observed: false
Default: false
Indicates whether the modal is currently open. This attribute can be used to control the visibility of the modal. Not observed since the css will handle the visibility.

size

Observed: false
Default: false
Specifies the size of the modal. It can be set to sizes from 1-4 where 1 is the smallest and 4 is the largest.

Methods

open_modal()

Opens the modal dialog. This method can be called to display the modal to the user.

close_modal()

Closes the modal dialog. This method can be called to hide the modal from the user.

on_backdrop_click(event)

Handles the click event on the modal backdrop. If quick-close is set to true, it will close the modal when the backdrop is clicked.

on_keydown(event)

Handles the keydown event for the modal. If the Escape key is pressed and quick-close is set to true, it will close the modal.

on_ok_button_click()

Handles the click event on the OK button. If has-ok-confirm is set to true, it will prompt for confirmation before executing the callback.

on_cancel_button_click()

Handles the click event on the Cancel button. If has-cancel-confirm is set to true, it will prompt for confirmation before closing the modal.

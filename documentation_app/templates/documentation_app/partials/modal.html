Modal

File: GalaxyModal.js
Tag: galaxy-modal
Extends: GalaxyHTMLComponentBase
The GalaxyModal component is a modal dialog that can be used to display content in a popup window. It extends the GalaxyHTMLComponentBase class and provides additional functionality for managing modal dialogs.

Accessibility: the dialog has role="dialog" and aria-modal="true", and is labelled by its title; the "×" button is labelled "Close". Opening a modal moves focus into it, Tab and Shift+Tab stay inside the topmost open modal (through its footer buttons), and closing it returns focus to wherever it was. While any modal is open, the page behind does not scroll.

Attributes

has-ok-confirm

Observed: true
Default: false
Indicates whether the modal will have confirmation on the OK button. Reactive: toggling this after creation keeps the built-in OK button's own has-confirm in sync.

has-cancel-confirm

Observed: true
Default: false
Indicates whether the modal will have confirmation on the Cancel button. Reactive: toggling this after creation keeps the built-in Cancel button's own has-confirm in sync.

quick-close

Observed: false
Default: false
Indicates whether the modal can be closed quickly using the Escape key or by clicking outside the modal. Escape closes only the topmost open modal, so one press closes one modal, and a quick-close modal under one that is not quick-close stays open.

open

Observed: true
Default: false
Indicates whether the modal is currently open, and opens or closes it. However it changes - this attribute, the open property, open_modal() or close_modal() - a nested modal resizes its parent while open and gives the parent its size back when it closes or is removed, and the modal joins or leaves the stack of open modals that Escape works through.

size

Observed: false
Default: false
Specifies the size of the modal. It can be set to sizes from 1-4 where 1 is the smallest and 4 is the largest.

ok-button-text

Observed: true
Default: OK
The OK button's label. Shown as text: markup in it is not parsed. Removing the attribute restores the default.

ok-button-type

Observed: true
Default: success
The OK button's type (its color). Removing the attribute restores the default.

ok-button-icon

Observed: true
Default: none
The OK button's icon, e.g. save or confirm. Removing the attribute restores the default.

cancel-button-text

Observed: true
Default: Cancel
The Cancel button's label. Shown as text: markup in it is not parsed. Removing the attribute restores the default.

cancel-button-type

Observed: true
Default: danger
The Cancel button's type (its color). Removing the attribute restores the default.

cancel-button-icon

Observed: true
Default: none
The Cancel button's icon, e.g. cancel. Removing the attribute restores the default.

hide-cancel

Observed: true
Default: false
Hides the Cancel button, for a modal with a single action. Removing the attribute restores the default.

Methods

open_modal()

Opens the modal dialog. This method can be called to display the modal to the user.

close_modal()

Closes the modal dialog. This method can be called to hide the modal from the user.

on_backdrop_click(event)

Handles the click event on the modal backdrop. If quick-close is set to true, it will close the modal when the backdrop is clicked.

on_keydown(event)

Handles the keydown event for the modal. If the Escape key is pressed, quick-close is set and this is the topmost open modal, it closes the modal and marks the Escape used - unless something inside the modal already used that Escape (its default was prevented), such as closing an open select.

on_ok_button_click()

Handles the click event on the OK button. If has-ok-confirm is set to true, it will prompt for confirmation before executing the callback.

on_cancel_button_click()

Handles the click event on the Cancel button. If has-cancel-confirm is set to true, it will prompt for confirmation before closing the modal.

async on_create()

See GalaxyHTMLComponentBase . Builds the modal and wires its title, close button, OK and Cancel buttons, backdrop and Escape key in the same step, so set_title() and the buttons work as soon as the modal is created. It then resolves ready and dispatches a ready event on the element.

async on_destroy()

See GalaxyHTMLComponentBase

Getters / Setters

confirm_callback

get: Gets the modal callback of the OK button.
set: Sets the modal callback of the OK button. It may be set before the modal is created; with has-ok-confirm it reaches the OK button's confirmation when the modal is created, and again after a move.

cancel_callback

get: Gets the modal callback of the cancel button.
set: Sets the modal callback of the cancel button.

has_ok_confirm

get: Gets the has-ok-confirm state of the modal.
set: Sets the has-ok-confirm state of the modal.

has_cancel_confirm

get: Gets the has-cancel-confirm state of the modal.
set: Sets the has-cancel-confirm state of the modal.

quick_close

get: Gets the quick-close state of the modal.
set: Sets the quick-close state of the modal.

open

get: Gets the open state of the modal.
set: Sets the open state of the modal.

size

get: Gets the size of the modal.
set: Sets the size of the modal.

ready

get: A promise that resolves once the modal is built and wired, at the same moment it dispatches its ready event (await modal.ready;). When the modal is removed, it is replaced with a new pending promise, which resolves when the modal is wired again on reconnect.

Observers

Example


            
        

            let modal = document.getElementById('example_modal');
            let open_modal_button = document.getElementById('open_modal_button');

            // Set the confirm and cancel callbacks
            modal.confirm_callback = () => {
                console.log('OK button clicked');
            };

            modal.cancel_callback = () => {
                console.log('Cancel button clicked');
            };

            // Open the modal when the button is clicked
            open_modal_button.addEventListener('click', () => {
                modal.open_modal();
            });

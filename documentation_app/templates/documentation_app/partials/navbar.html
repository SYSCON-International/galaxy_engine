Navbar

File: GalaxyNavbar.js
Tag: galaxy-navbar
Extends: GalaxyNavbarBase
A horizontal top-bar navigation component: left/center/right sections, an optional brand block, dropdowns (single-column and multi-column mega-menu), and current-page highlighting. Its only own member is layout_option -- everything else (attributes, config shape, dropdown behavior) is documented on Navbar Base. Sidebar is the vertical/collapsible counterpart.

Attributes

None

No attributes of its own -- see Navbar Base for theme, config, and disable-hover.

Methods

None

No methods of its own -- see Navbar Base.

Getters / Setters

static layout_option

get: Returns "horizontal". This is what Navbar Base's layout getter reads to determine which orientation (and dropdown-positioning logic) this nav uses.

Observers

None

No observers of its own -- see Navbar Base.

Example


            
        

            let navbar = document.querySelector('#main_nav');

            navbar.config = {
                brand: {name: "Galaxy Engine", logo_url: "/assets/logo.svg", link: "/", tagline: "The future of frontend", should_show: true},
                navigation: [
                    {label: "Dashboard", icon: "fas fa-home", link: "/dashboard"},
                    {
                        label: "Reports",
                        icon: "fas fa-chart-line",
                        multi_column: true,
                        columns: [
                            {title: "Production", items: [{label: "Live Feed", link: "/reports/live"}, {label: "Summary", link: "/reports/summary"}]},
                            {title: "Maintenance", items: [{label: "Schedule", link: "/reports/maintenance/schedule"}]}
                        ]
                    },
                    {label: "Documentation", icon: "fas fa-book", link: "https://docs.galaxyengine.dev", section: "right"},
                    {
                        type: "button",
                        label: "Sign Out",
                        icon: "fas fa-right-from-bracket",
                        section: "right",
                        onclick: () => console.log("Sign out clicked")
                    }
                ]
            };

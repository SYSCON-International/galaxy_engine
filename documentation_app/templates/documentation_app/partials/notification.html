Notification

File: GalaxyNotification.js
Tag: galaxy-notification
Extends: GalaxyHTMLComponentBase
The galaxy-notification component is a custom HTML element that displays a notification message to the user. It can be used to provide feedback, alerts, or any other type of message that requires the user's attention. Announced to assistive tech as a polite status region (role="status", aria-live="polite"). Most consumers won't construct this directly -- Notification Manager creates and manages instances for you, with auto-expiry and stacking.

Attributes

None

Configured via a plain object passed to the constructor -- new GalaxyNotification({type, title, message}) -- rather than attributes, since that's what Notification Manager's add(type, message, duration) already builds and passes. All three fields are optional: type is one of "info" (default)/"success"/"error"/"warning" (also selects the icon and color, via set_icon()); title defaults to type, capitalized; message defaults to an empty body. Note: custom-element construction via markup or document.createElement always invokes the constructor with no arguments regardless of this parameter -- the config object defaults to {} for exactly that case, so this still renders (as a default "Info" notification with no body) rather than throwing; pass a real config via new GalaxyNotification(config) for anything else.

Methods

show()

Shows the notification by removing the "hide" class, which triggers the CSS transition to make the notification visible. The notification will remain visible until it is hidden by calling the `hide` method or by clicking the close button.

hide()

Hides the notification by adding the "hide" class, which triggers the CSS transition to fade out the notification, then removes it from the DOM once the fade-out completes. This is self-contained -- a galaxy-notification shown without Notification Manager still cleans itself up correctly when its own close button is clicked.

set_event_listeners()

Sets up event listeners for the notification component. This includes adding a click event listener to the close button, which will call the `handle_close_button_click` method to hide the notification when the close button is clicked.

set_icon()

Sets the icon for the notification based on the type specified in the configuration. The method looks up the appropriate icon for the notification type and updates the header icon accordingly. If the specified type is not found in the list of types, it defaults to the first type in the list.

handle_close_button_click()

Handles the click event on the close button. When the close button is clicked, this method is called to hide the notification by calling the `hide` method.

Example

Prefer Notification Manager for normal use (see its own example) -- this is the direct, manager-free path:

            let notification = new GalaxyNotification({type: "success", title: "Saved", message: "Your changes were saved."});

            document.body.appendChild(notification);
            notification.show();

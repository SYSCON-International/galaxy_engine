Tabs

File: GalaxyTabs.js, GalaxyTab.js
Tag: galaxy-tabs, galaxy-tab
Extends: GalaxyHTMLComponentBase
A tabbing system. Each <galaxy-tab label="..."> inside a <galaxy-tabs> is one tab: its content is everything inside it -- any markup, Galaxy components and forms included -- and its label is its text in the tab bar. The bar is built from the galaxy-tab children, so a tab and its panel can never get out of step, and adding, removing, relabeling, badging, or disabling a galaxy-tab updates it. Only the selected tab shows; every tab stays in the page, so the fields in hidden tabs keep their values and are still submitted with their form. A tab being hidden closes anything floating from inside it, such as an open select dropdown.

A click selects a tab. With the bar focused, the arrow keys move through the tabs, selecting each one (Left and Right, or Up and Down when vertical), and Home and End go to the ends; disabled tabs are skipped. When the tabs do not fit, the bar scrolls sideways with arrow buttons at its ends, and the selected tab is kept in view.

A tab holding an invalid field is marked with a red dot, and a Form that finds its first invalid field inside a tab selects that tab, through the tab's reveal().

The selection can be remembered, with one remember attribute: in the URL, or in the app's session. It can also be bound to the Galaxy state manager with property-name, like any Galaxy input, so other controls bound to the same property stay in step. The starting tab is the remembered one, else the state value, else selected, else the first enabled tab.

galaxy-tabs Attributes

selected

Observed: true
Default: the first enabled tab
The selected tab's name. A disabled or missing tab selects the first enabled one instead, and the attribute is updated to name the tab actually shown.

orientation

Observed: true
Default: "horizontal"
"vertical" puts the tab bar down the left side, with the panels beside it -- for settings-style pages.

label

Observed: true
Default: null
The tab bar's name for screen readers.

remember / remember-key

Observed: false (read when the tabs are created)
Default: null / the element's id
Where the selection is remembered, under remember-key (or the element's id):
  • "url" -- in the page's URL, as ?<key>=<tab name>, replaced on each change, so a reload, back and forward, and a shared link all land on that tab.
  • "session" -- in the app's session, through window.galaxy_session_store, an object the app registers with get(key) (which may return a promise) and set(key, value). The stored tab is read after the tabs show, so the default tab shows first, then switches -- unless the user has already chosen one. Without a store, it warns once and remembers nothing.
Without remember, nothing is remembered.

property-name

Observed: false
Default: null
Binds the selected tab's name to this state manager property, both ways: a user's selection writes it, and a change made anywhere else selects that tab.

galaxy-tab Attributes

label / name

Observed: true
Default: "" / tab_<index>
The tab's text in the bar, and the name selected, remember, state, and events know it by.

disabled

Observed: true
Default: false
Boolean. The tab shows in the bar but cannot be selected; the keyboard skips it.

badge / badge-variant

Observed: true
Default: null / "info"
A small count or marker beside the label -- "3", "New" -- and its look: "info" or "danger".

Methods

select_tab(name)

galaxy-tabs. Selects a tab from code, without dispatching tab_change.

refresh_error_marks()

galaxy-tabs. Re-marks the tabs holding an invalid field. It runs on its own after a form's validation reveals a tab and after any input or change inside the tabs; call it after changing fields' validity from code.

reveal()

galaxy-tab. Selects the tab so its content can be seen -- the shared hook a Form calls on the ancestors of its first invalid field.

Getters / Setters

selected / orientation (galaxy-tabs)

get/set: The selected tab's name -- setting it dispatches no event -- and the orientation.
get: tabs lists the galaxy-tab children; selected_tab is the selected one.

label / name / disabled / badge / badge_variant (galaxy-tab)

get/set: Mirror the matching attributes; name reads back tab_<index> for a tab without one.
get: selected is whether the tab is the selected one.

Events

tab_change

Bubbling, dispatched when a user's click or key selects another tab: {name, previous_name, index}.

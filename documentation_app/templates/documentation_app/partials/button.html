Button

File: GalaxyButton.js
Tag: galaxy-button
Extends: GalaxyHTMLComponentBase
The galaxy-button component is a custom button element that extends the functionality of the base component. It allows for easy creation of buttons that can display a confirmation modal when clicked and can be customized with various attributes. Its inner <button> is named part="button", so a page stylesheet can style it, e.g. galaxy-button::part(button) { text-transform: uppercase; }. The label is the element's content, kept as one piece beside the icon; a button with no content (<galaxy-button icon="save"></galaxy-button>) shows only its icon.

Attributes

type

Observed: false (styled from the attribute)
Default: none (blue)
The button's color: none for the default blue, danger (red), success (green), warning (yellow), secondary (grey) or light (near-white with dark text).

size

Observed: false (styled from the attribute)
Default: none (regular)
sm for a smaller button or lg for a larger one. Any other value is the regular size.

block

Observed: false (styled from the attribute)
Default: false
Makes the button fill the full width of its container.

disabled

Observed: true
Default: false
Disables the button, as on a native button: it is drawn faded with a not-allowed cursor, cannot be focused, and a click - by the user, or element.click() from code - reaches no click listener on the element and opens no confirmation.

submit

Observed: false
Default: false
Makes the button submit its form when clicked, as a native submit button does - a galaxy-form (validated, then its submit event, then a post with native-submit) or a native <form>. Unlike a native <button>, a galaxy-button never submits by default, and the attribute is not type, which sets the button's color. With has-confirm, the form is submitted once the user confirms. In a form with submit-on-enter, the form's first submit control is its default button: Enter in one of its single-line Galaxy fields activates it. The button's own name and value are not submitted.

form

Observed: false (read when the button is clicked)
Default: none - the form the button is in
The id of the form a submit or reset button acts on, so the button can sit outside it, as with a native button's form attribute. It can name a galaxy-form, wherever it is (inside another component's shadow root too), or a native <form>; a native button cannot target a galaxy-form, so use this. An id that matches no form gives the button no form, and it does nothing. It wins over the form around the button. A button outside its form is never that form's default button for Enter.

reset

Observed: false
Default: false
Makes the button reset its form when clicked, as a native reset button does: every field returns to the value it was created with. A button with submit as well submits.

has-confirm

Observed: true
Default: false
Displays a confirmation modal when the button is clicked. The modal's title, body, ok button, and cancel button can all be changed via attributes. Callbacks for the ok and cancel buttons can also be set using the getters/setters for confirm_callback and cancel_callback. Reactive: the confirm modal is built lazily the first time this becomes true, whether that's at initial creation or added later on an already-connected button.

confirm-title-text

Observed: true
Default: "Confirm"
Sets the text of the confirmation modal's title element if has-confirm is true. If no value is provided, it defaults to "Confirm".

confirm-body-text

Observed: true
Default: "Are you sure?"
Sets the text of the confirmation modal's body element if has-confirm is true. If no value is provided, it defaults to "Are you sure?".

confirm-button-text

Observed: true
Default: "OK"
Sets the text of the confirmation modal's ok button if has-confirm is true. If no value is provided, it defaults to "OK".

cancel-button-text

Observed: true
Default: "Cancel"
Sets the text of the confirmation modal's cancel button if has-confirm is true. If no value is provided, it defaults to "Cancel".

confirm-button-type / confirm-button-icon / cancel-button-type / cancel-button-icon

Observed: true
Default: the dialog's own (OK green, Cancel red, no icon)
The color (type) and icon of the confirmation modal's OK and Cancel buttons if has-confirm is true -- e.g. confirm-button-type="danger" confirm-button-icon="delete" for a delete. They are passed to the dialog's ok-button-type/ok-button-icon and cancel-button-type/cancel-button-icon; removing one restores the dialog's default.

Methods

on_button_click()

Handles the built-in click event for the button. If the button has confirmation enabled, it will show a confirmation modal. It will also update the modal's title, body, and button texts based on the component's attributes. Without a confirmation, it submits or resets the button's form (see run_form_action()).

on_confirm_modal_ok_button_click()

Handles the confirm modal button click event. Triggers the confirm callback if provided, closes the modal, then submits or resets the button's form.

activate()

Acts as a click on the button would: a confirmation when it has one, then its form's submit or reset. A disabled button does nothing. Unlike element.click(), which is dispatched on the element itself, this reaches the button's own click handling - it is how Enter in a field activates a galaxy-button that is its form's default button.

run_form_action()

Submits (requestSubmit()) or resets the button's form, per its submit and reset attributes. A button with neither, or in no form, does nothing.

on_confirm_modal_cancel_button_click()

Handles the cancel button click event in the confirm modal. Triggers the cancel callback if provided and closes the modal.

Getters / Setters

textContent

get: Gets the text content of the button.
set: Sets the text content of the button to the specified value.

confirm_callback

get: Gets the callback function that is called when the ok button is clicked and confirmation is required.
set: Sets the callback function that is called when the ok button is clicked and confirmation is required.

cancel_callback

get: Gets the callback function that is called when the cancel button is clicked and confirmation is required.
set: Sets the callback function that is called when the cancel button is clicked and confirmation is required.

confirm_title_text

get: Gets the text of the confirmation modal's title element if confirmation is required.
set: Sets the text of the confirmation modal's title element if confirmation is required.

confirm_body_text

get: Gets the text of the confirmation modal's body element if confirmation is required.
set: Sets the text of the confirmation modal's body element if confirmation is required.

confirm_button_text

get: Gets the text of the confirmation modal's ok button if confirmation is required.
set: Sets the text of the confirmation modal's ok button if confirmation is required.

cancel_button_text

get: Gets the text of the confirmation modal's cancel button if confirmation is required.
set: Sets the text of the confirmation modal's cancel button if confirmation is required.

disabled

get: Whether the button is disabled.
set: Disables or enables the button by setting or removing the disabled attribute.

submit

get: Whether the button submits its form.
set: Sets or removes the submit attribute.

reset

get: Whether the button resets its form.
set: Sets or removes the reset attribute.

form

get: The form the button submits or resets: with a form attribute, the galaxy-form's internal form or native form with that id; otherwise the nearest <form> around it - inside a galaxy-form, its internal form - or else its galaxy-form's. Null when it has none. Looked up on every read.

Observers

handle_observed_confirm_title_text(new_value)

Handles the confirm title attribute change. If no value is provided, it defaults to "Confirm".

handle_observed_confirm_body_text(new_value)

Handles the confirm body attribute change. If no value is provided, it defaults to "Are you sure?".

handle_observed_confirm_button_text(new_value)

Handles the confirm button text attribute change. If no value is provided, it defaults to "OK".

handle_observed_cancel_button_text(new_value)

Handles the cancel button text attribute change. If no value is provided, it defaults to "Cancel".

Setting Callbacks


        // Get the button element
        let button_element = document.querySelector('galaxy-button');

        // Set the confirm and cancel callbacks
        button_element.confirm_callback = () => {
            console.log('Confirmed!');
        };

        button_element.cancel_callback = () => {
            console.log('Cancelled!');
        };

Combo Box

File: GalaxyComboBox.js
Tag: galaxy-combo-box
Extends: GalaxyTextInput
A free-text field with suggestions -- a format field, for one, where a common pattern can be picked or one's own typed. The typed text is always the value; everything else is a Text Input's.

The suggestions show in a list styled like a Select's floating dropdown, which floats above the page and flips above the field when there is no room below. Typing shows the suggestions containing the typed text (ignoring case), and closes the list when none match, so typing one's own value is never in the way; a click in the field, the down arrow, or ArrowDown shows them all. ArrowUp and ArrowDown move through the list, wrapping at the ends; Enter or a click picks a suggestion, and Escape, Tab, or leaving the field closes it. Enter with nothing highlighted is left to the field and the page (see Form for how a form is submitted). The keys the list uses stop there, so a page's own document-level key handling does not act on them too. Picking a suggestion puts its value in the field as if it had been typed, so input fires and the form value and any bound state follow, and then change fires on the element, as for any committed edit. The suggestion matching the field's value is shown in bold. Without suggestions the down arrow hides and the field is free text alone, and a disabled or read-only field shows none. A Collapse closing around the field closes its list.

Attributes

suggestions

Observed: true
Default: null
A JSON array of strings, or of {value, text} objects whose text is shown in the list and whose value is put in the field. See Input Base for disabled, label, name, readonly, required, value, property-name, and placeholder. An Editable Table column of type "combo-box" passes its suggestions option to its cells.

Methods

open_suggestions(suggestions, is_filtered) / close_suggestions() / pick_suggestion(suggestion)

Open the list showing the given suggestions (closing it when there are none to show), close it, or put a suggestion's value in the field as if typed. close_floating_content() closes the list too.

Getters / Setters

suggestions

get: Copies of the suggestions, each normalized to {value, text}.
set: An array (or JSON string) of strings or {value, text} objects; null or [] for none.

has_suggestions

get: Whether there are suggestions to offer.

Observers

apply_suggestions(value)

Handles changes to the suggestions attribute, refreshing an open list and showing or hiding the down arrow.

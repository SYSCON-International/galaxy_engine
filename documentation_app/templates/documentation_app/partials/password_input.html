Password Input

File: GalaxyPasswordInput.js
Tag: galaxy-password-input
Extends: GalaxyTextInput
A password field: a Text Input that masks its value, with a show/hide toggle inside the field's right edge, a Caps Lock warning under the field while it is focused, and an autocomplete hint for browsers and password managers. label, name, required, placeholder, readonly, disabled, and validation come from Input Base.

It keeps the password inside the field. property-name is ignored with a console warning, so the password never enters the State Manager. A value set from code is written to the field and form value but never reflected to the value attribute, so it does not show in devtools or outerHTML. And it submits no restore state, so the browser does not keep it in session history. It is submitted with its form like any other field.

Attributes

autocomplete

Observed: true
Default: "current-password"
Forwarded to the field. "current-password" for a login field, "new-password" for a set or change-password field (so password managers offer to generate and save one), or "off".

hide-visibility-toggle

Observed: true
Default: false
Boolean. Removes the show/hide toggle; a password being shown is masked again.

caps-lock-message

Observed: true
Default: "Caps Lock is on"
The Caps Lock warning's text, e.g. a translated string.

property-name

Observed: false
Default: null
Not supported: logs a console warning and is ignored, so the password stays out of the State Manager.

Methods

show_password() / hide_password()

Shows the password as plain text or masks it, keeping the caret and selection where they were and updating the toggle's label ("Show password" / "Hide password") and aria-pressed. The toggle calls these; pressing it with the mouse leaves focus in the field. A form reset masks the password again.

Getters / Setters

value

get: The password.
set: Writes the password to the field and the form value, without reflecting it to the value attribute; null/undefined clear it.

is_password_visible

get: Whether the password is currently shown as plain text.

autocomplete / hide_visibility_toggle / caps_lock_message

get/set: Mirror the matching attributes.

Loader

File: GalaxyLoader.js
Tag: galaxy-loader
Extends: GalaxyHTMLComponentBase
A loading indicator component. Can be displayed fullscreen (covering the viewport) or scoped to an individual element (positioned to fill its nearest positioned ancestor). Defaults to a "drip" spinner look and feel, but supports a custom image via the image-url attribute and/or custom CSS via custom_style. Most consumers won't construct this directly -- Loader Manager creates and manages instances for you, with reference-counted show/hide.

Attributes

fullscreen

Observed: false
Default: false
When present, the loader covers the entire viewport (fixed position) instead of just its positioned ancestor.

image-url

Observed: true
Default: null (default drip spinner)
A custom image URL. When set, the default drip spinner is replaced by an <img> pointing at this URL.

message

Observed: true
Default: "Loading"
Text shown below the spinner/image. Set to an explicit empty string to hide the message row entirely; leaving the attribute off entirely falls back to "Loading".

Methods

update_image()

Updates the visible spinner/image based on the current image_url. Falls back to the default drip spinner when no custom image URL is set.

update_message()

Updates the visible message text based on the current message.

async on_create()

See GalaxyHTMLComponentBase

async attribute_changed_callback(name, old_value, new_value)

See GalaxyHTMLComponentBase

Getters / Setters

fullscreen

get: Gets the fullscreen state of the loader.
set: Sets or removes the fullscreen attribute.

image_url

get: Gets the custom image URL, or null if the default spinner is being used.
set: Sets or clears the image-url attribute.

message

get: Gets the message text, defaulting to "Loading" when no message attribute has been set.
set: Pass an empty string (not null/undefined) to hide the message row while still overriding the default; null/undefined clear the attribute instead, reverting to "Loading".

custom_style

get: Gets the custom CSS most recently applied.
set: Applies a custom CSS string to the loader's shadow DOM, layered on top of the default styles so it can override them -- use this (rather than an attribute) since a CSS block is unwieldy as an HTML attribute value. Deliberately keeps a single CSSStyleSheet and updates it in place on re-assignment, rather than always adding a new one.

Observers

None

image-url and message are both handled by update_image()/ update_message() via a single attribute lookup table rather than per-attribute observer methods.

Example


            
        

            // Prefer Loader Manager over constructing/inserting  directly, so multiple
            // concurrent callers share one loader with reference-counted show/hide.
            let token = window.galaxy_engine.loaders.show_fullscreen({message: "Saving...", image_url: "/static/img/spinner.svg"});

            fetch("/api/save").finally(() => window.galaxy_engine.loaders.hide_fullscreen(token));

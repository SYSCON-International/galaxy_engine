Number Input Base

File: GalaxyNumberInputBase.js
Tag: N/A
Extends: GalaxyInputBase
A parent class for integer and float input types. Contains common functionality for number inputs, such as min, max, and step attributes.

Attributes

min

Observed: false
Default: null
The minimum value for the number input. If not set, there is no minimum limit.

max

Observed: false
Default: null
The maximum value for the number input. If not set, there is no maximum limit.

step

Observed: true
Default: "Any"
The step value for the number input. This defines the increment or decrement value when using the up/down buttons.

Methods

cast_value_for_input_type(value)

Casts the value to the correct type for the number input. If the input is a float, the value is parsed as a float. If the input is an integer, the value is parsed as an integer.

async attribute_changed_callback(name, old_value, new_value)

Casts the value to the correct type for the number input. If the input is a float, the value is parsed as a float. If the input is an integer, the value is parsed as an integer.

get_validation_errors(value)

Validates the value against the min, max, and step attributes. Returns an array of error messages if the value is invalid.

See GalaxyInputBase

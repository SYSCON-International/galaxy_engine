Time Picker

File: GalaxyTimePicker.js
Tag: galaxy-time-picker
Extends: GalaxyDatetimePickerBase
A time-only picker. A thin subclass of Datetime Picker Base that only passes "time" as the mode -- its full API (attributes, popup behavior, value shapes) is documented there.

Attributes

None

No attributes of its own -- see Datetime Picker Base for label, time-format, and value.

Methods

None

No methods of its own -- see Datetime Picker Base.

Example


            
        

            let shift_start = document.querySelector('#shift_start');

            shift_start.value = {hour: 6, minute: 30};

            console.log(shift_start.value_dictionary); // {__type__: "time", hour: 6, minute: 30, ...}

Datetime Range

File: GalaxyDatetimeRangePickerBase.js
Tag: galaxy-datetime-range
Extends: GalaxyInputBase
A datetime range picker: a preset-range select (All, Today, This Week, This Month, Custom) and, only when Custom is selected, a pair of start/end Datetime Picker fields. It is a full form field, like every other Galaxy input: it submits its range with its form, binds to state through property-name, validates, resets, restores, and follows disabled and readonly -- its own or a disabled fieldset's. Its value is kept by the element itself, so it can be set before the element is created and survives a move. Note: despite the "Base" in its class name, this is the actual registered, consumer-facing element -- there is no separate leaf subclass, unlike Date Picker/Time Picker/Datetime Picker, which each have a thin subclass of their own base.

Attributes

value

Observed: true
Default: "All"
The initial range: a range name (value="Today") or JSON (value='{"range": "Custom", "start": "2026-01-01T00:00", "end": "2026-01-31T23:59"}'). A form reset returns to it. Changing it later sets the value; removing it sets "All". The element never writes it back.

name

Observed: true
Default: none
The form field name. The submitted value is JSON: {"range": "...", "start": "...", "end": "..."}, with start and end as canonical datetimes (YYYY-MM-DDTHH:mm) for Custom and null otherwise (see form_value).

required

Observed: true
Default: false
A preset range is always a value. A Custom range with neither a start nor an end is empty, so it fails required. Whether required or not, a Custom range is invalid with only one end, with a start after its end, or with text that is not a datetime (see get_validation_errors()).

disabled / readonly

Observed: true
Default: false
Applied to the select and both pickers (see apply_control_states()). A disabled fieldset disables them too. A select cannot be read-only, so a read-only range picker disables its select; its value is still submitted.

property-name

Observed: false
Default: none
Binds the range to a State Manager property, as for every Galaxy input. The state holds the value getter's object; a user change writes it, and a state change sets it.

custom-range

Observed: false -- set by the element
Default: false
Present when the range is Custom; shows the start/end datetime fields via CSS. The element keeps it in step with the value -- setting it directly does not change the range.

Methods

parse_range_value(new_value)

Reads a value in any accepted form (an object, its JSON, a range name, or empty) into the canonical {range, start, end}, with the start and end as canonical datetimes or "". A start/end dictionary whose parts are all null -- what the getter gives for an empty date -- is empty (see to_canonical_datetime()), so a value read from the getter and set back is unchanged.

on_user_edit(event)

Handles the user changing the range or a date (the select's change, a picker's input or change): the value and form value follow, the state is written, the picker revalidates when its form validates instantly, and a committed change (change, not input) is dispatched on the element as change.

apply_control_states()

Disables the select and both pickers when the range picker is disabled (its own attribute or a fieldset), and makes the pickers read-only and the select disabled when it is read-only. Runs on create, when either attribute changes, and when a fieldset disables or enables it.

get_validation_errors() / is_value_empty()

For a Custom range only: text in a picker that is not a datetime ("Invalid date/time format."), a range with only one end ("Please enter both a start and an end."), and a start after the end ("The start must not be after the end."). is_value_empty() is true only for a Custom range with neither end.

on_range_change(event)

Fires whenever anything that affects the current range changes -- the preset select, or either nested picker's value (bound to both's input_validated event, which Datetime Picker Base dispatches on every value change). A picker value changed from code is read into the value -- only that picker's, since the other may not have finished creating. Dispatches the debounced range_change event, and range_valid if is_range_valid().

is_range_valid()

Whether the current selection is complete and well-formed. A preset range ("All", "Today", etc.) is always valid on its own; "Custom" requires both a start and an end, and no validation error.

async on_create()

Builds the preset select and a start/end pair of Datetime Picker elements, inserts them after the label row, shows the current value in them, applies disabled/readonly, sets the form value, and wires listeners. Runs again after a move, showing the value the element kept. See also GalaxyHTMLComponentBase.

Getters / Setters

value

get: Returns {start, end, range}: range is the selected range, and start/end are {year, month, day, hour, minute, ...} dictionaries (parts all null when empty) for "Custom", and null otherwise. Safe to read before the element is created.
set: Takes {range, start, end}, its JSON, or a range name; an empty value is "All". An unknown range is "All", and a value without a range keeps the current one. start/end take anything a datetime picker does (a canonical datetime, a dictionary); a missing one is empty. Updates the select, pickers, custom-range and form value, and dispatches range_change; like setting any input's value from code, it dispatches no change. Safe before creation -- the value is shown once the element is created.

form_value

get: The JSON submitted with the form: {"range": "...", "start": "...", "end": "..."}, with start/end as canonical datetimes (or null when empty) for "Custom" and null otherwise. A restored form state is read back through the value setter.

Observers

handle_observed_value(new_value)

The value attribute is read like the value setter's argument; a removed attribute is "All". disabled and readonly are observed through the input base and also applied to the controls. range_change/range_valid are plain custom events, not attribute observers.

Example


            
                
            
        

            let report_range = document.querySelector('galaxy-form').get_field('report_range');

            report_range.addEventListener('range_change', (event) => console.log('range changed:', event.detail));
            report_range.addEventListener('range_valid', (event) => console.log('range is complete:', event.detail));

            report_range.value = {range: "Custom", start: "2026-01-01T00:00", end: "2026-01-31T23:59"};

            console.log(report_range.value); // {start, end, range}

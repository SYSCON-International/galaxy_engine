Table

File: GalaxyTable.js
Tag: galaxy-table
Extends: GalaxyHTMLComponentBase
A data table with sortable headers. Data comes from columns and rows, or, when no columns are supplied, from a light-DOM <table> child read as a declarative data source (its cell markup is cloned into the rendered table, and edits to it re-render). Clicking a sortable header sorts by that column alone, cycling ascending, descending, unsorted; shift-clicking adds the column to the existing sort, or cycles it within it. Sorted headers show an arrow, plus their position in the order when more than one column is sorted. Rows are only reordered locally when client-sort is set; otherwise respond to sort_change by supplying sorted rows. Rows dispatch row_click only when clickable-rows is set. Light-DOM children other than the <table> are slotted over the table's area, so an element loader shown on the table itself (loaders.show_element(table)) covers it.

Attributes

columns

Observed: true
Default: null (use the light-DOM <table>)
A JSON array of {key, label, sortable, align, width}. label defaults to key; align is "left", "center", or "right"; width is any CSS width. Takes precedence over a light-DOM table. Through the columns property only (a function cannot travel in JSON), a column may also carry render(value, row), returning a string (always shown as text, never markup) or a Node (appended as-is). A render that throws falls back to the raw value. Client-side sorting always uses the raw value, not the rendered result. A column may likewise carry tooltip(value, row), returning its cell's tooltip text ("" or null for none); it wins over row_tooltip within its cells.

rows

Observed: true
Default: []
A JSON array of row objects keyed by column key. Values render as text, never markup. Prefer the rows property for anything beyond a handful of rows.

sort

Observed: true
Default: []
The initial sort order, a JSON array of {key, direction} with direction "asc" or "desc", highest priority first. Entries naming a missing or unsortable column are dropped. Not updated by header clicks; read the sort property for the current order.

client-sort

Observed: true
Default: false
Boolean. Reorders rows locally on a sort change. Intended for small tables. Numbers and dates compare numerically, text compares with numeric awareness ("Item 2" before "Item 10"), and empty values (null, undefined, "") sort last in both directions.

clickable-rows

Observed: true
Default: false
Boolean. Makes rows focusable, shows a pointer and highlight on hover, and dispatches row_click on a click, or on Enter or Space while a row is focused. A click on, or a key pressed in, a link, button, or field inside a cell is left to it and does not count. Without it, rows dispatch nothing.

empty-message

Observed: true
Default: "No data"
The message shown, spanning every column, when there are no rows.

max-body-height

Observed: true
Default: null
A CSS length. The table's height is capped at it and the body scrolls under a sticky header.

page-size / page

Observed: true
Default: null / 1
With a page-size, the table shows one page (1-based) of its rows -- sorted first when client-sort sorts them. The page is clamped to the pages there are, so removing rows never leaves it past the end. A Pagination linked with for sets both. Without a page size, every row shows.

Light-DOM Table Attributes

<th> data-key / data-sortable / data-align / data-width

The column's key (default column_<index>), whether it is sortable (present and not "false"), its alignment, and its width. Header cells come from the <thead>'s first row, or the table's first row when there is no <thead>.

<td> data-sort-value

The value to sort by instead of the cell's text. Numeric strings sort numerically.

Methods

create_row_element(row_entry, columns)

Builds one body row (its <tr> carries data-row-id). render_body() calls it for every row; a subclass overrides it to render its own cells, and calls it again to replace a single row. Editable Table does both.

create_extra_header_cells() / extra_column_count

Hooks for a subclass that adds columns after the data columns -- the header cells it adds, and how many, so the empty-state row still spans the table. None by default.

create_leading_header_cells() / leading_column_count

The same hooks for columns added before the data columns, as Sortable List's drag handles are. None by default.

create_control_tooltip(control, text)

For a subclass: wraps a control it puts in a row -- an icon-only button -- so the table's shared tooltip shows text for it, even while the button is disabled. Returns the wrapper. Any element in the table with a data-tooltip shows that text the same way, ahead of the column and row tooltips; a sortable header's sort button uses it to explain shift-clicking.

render()

Rebuilds the header and the body. Called automatically on every attribute, property, sort, or light-DOM change.

get_next_sort(key, is_additive)

Returns the sort order a header click would produce, without applying it.

Getters / Setters

columns

get: The column definitions in use, supplied or read from the light-DOM table.
set: An array (or JSON string) of column definitions; null reverts to the light-DOM table.

rows

get: The row objects in their supplied (unsorted) order.
set: An array (or JSON string) of row objects.

sort

get: A copy of the current sort order.
set: Applies a sort order without dispatching sort_change, e.g. to reflect a sort the server already applied.

client_sort

get/set: Mirrors the client-sort attribute.

clickable_rows

get/set: Mirrors the clickable-rows attribute.

row_tooltip

get/set: A function of the row returning its tooltip text, or "" or null for none. The table shows one shared tooltip for the hovered, focused, or touch-held row or cell, and gives each tooltip's text to screen readers as the row's or cell's aria-description. Set it to null for no row tooltips. Editable Table and Sortable List inherit it.

page / page_size / page_count / total_row_count

get/set: page and page_size mirror the attributes; page reads back clamped.
get: page_count is how many pages the rows fill (1 when the table is not paged); total_row_count is the rows across every page.

max_body_height

get/set: Mirrors the max-body-height attribute; null removes the limit.

empty_message

get/set: Mirrors the empty-message attribute; null reverts to "No data".

Events

sort_change

Fired after a header click changes the sort. event.detail.sort is the new order. Bubbles and is composed.

row_click

Fired, when clickable-rows is set, on a row click or on Enter or Space on a focused row. event.detail is {row, index, original_event}, where index is the row's position among the supplied rows, regardless of the display order. Bubbles and is composed.

table_render

Fired on the table after every render of its body, with {row_count, page, page_size}, for a Pagination linked with for to follow. Does not bubble.

            let table = document.querySelector('galaxy-table');

            table.columns = [
                {key: "name", label: "Machine", sortable: true},
                {key: "status", label: "Status", render: (value) => {
                    let badge = document.createElement("span");
                    badge.className = `status-badge ${value}`;
                    badge.textContent = value;
                    return badge;
                }},
            ];
            table.rows = [{name: "Press 1", status: "running"}, {name: "Press 2", status: "down"}];

            table.addEventListener("sort_change", (event) => console.warn(event.detail.sort));
            table.addEventListener("row_click", (event) => console.warn(event.detail.row));

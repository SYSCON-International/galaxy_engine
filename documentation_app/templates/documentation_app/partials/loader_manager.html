Loader Manager

File: GalaxyLoaderManager.js
Tag: N/A
Extends: N/A
Manages Loader indicators shown in the UI, either fullscreen or scoped to an individual element, instantiated as window.galaxy_engine.loaders. Callers are tracked with tokens (returned by the show_* methods) so that a loader triggered by multiple concurrent callers is only removed once every caller has released it via the matching hide_* method -- this prevents one caller's hide_* call from removing a loader another caller is still relying on.

Attributes

None

This is a plain JS manager class, not a custom element -- it has no attributes.

Methods

generate_token()

Generates a unique token to hand back to a show_* caller. The token must be passed to the matching hide_* method to release that caller's claim on the loader.

apply_loader_options(loader, options = {})

Applies the look-and-feel options (image_url, message, custom_style) to a newly-created loader. Only called once, when a loader is first shown -- per convention, the first caller's options determine the loader's appearance for as long as it is displayed, so a later concurrent caller with different options can't cause it to change (or flicker) out from under the first caller.

show_fullscreen(options = {})

Shows the fullscreen loader, creating it if it is not already visible. Returns a token that must be passed to hide_fullscreen() to release this caller's claim.

hide_fullscreen(token)

Releases a caller's claim on the fullscreen loader (from show_fullscreen()). The loader is only removed from the DOM once every caller that showed it has released their token. Warns via console.warn and no-ops on an unknown token.

is_loading_fullscreen()

Returns whether the fullscreen loader is currently being shown by any caller.

show_element(target_element, options = {})

Shows a loader scoped to target_element, creating it if the element doesn't already have one. If the element's computed position is static, it's temporarily switched to relative (restored once fully released) so the loader can be positioned to fill it. Returns a token (or null if no target element was given) that must be passed to hide_element() to release this caller's claim.

hide_element(target_element, token)

Releases a caller's claim on an element's loader (from show_element()). The loader is only removed (and the element's position style restored, if it was overridden) once every caller that showed it has released their token.

is_loading_element(target_element)

Returns whether the given element currently has a loader being shown by any caller.

Getters / Setters

None

This class has no getters/setters. Its per-element bookkeeping (element_loader_entries) is kept in a WeakMap keyed by the target element, so a caller that discards a target element without calling hide_element() first can't keep it (or its loader/tokens) alive forever.

Observers

None

This class has no attributes, so there are no attribute observers.

Example


            // Fullscreen loader
            let token = window.galaxy_engine.loaders.show_fullscreen({message: "Saving..."});

            fetch("/api/save")
                .finally(() => window.galaxy_engine.loaders.hide_fullscreen(token));

            // Element-scoped loader
            let panel = document.querySelector("#results_panel");
            let panel_token = window.galaxy_engine.loaders.show_element(panel);

            fetch("/api/results")
                .finally(() => window.galaxy_engine.loaders.hide_element(panel, panel_token));

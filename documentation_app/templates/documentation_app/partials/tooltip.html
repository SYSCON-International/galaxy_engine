Tooltip

File: GalaxyTooltip.js, GalaxyTooltipController.js
Tag: galaxy-tooltip
Extends: GalaxyHTMLComponentBase
A tooltip for icon-only buttons, hints, and anything else that needs a short explanation. It wraps its trigger -- <galaxy-tooltip text="Delete row"><button>...</button></galaxy-tooltip> -- or, with for, points at an element by id when the element cannot be wrapped. Table rows and cells get tooltips through the Table's row_tooltip and column tooltip options instead. Its content is its text, or markup it holds with slot="content", which wins over text. A tooltip is for reading: it should hold nothing interactive, since the keyboard cannot reach into it.

It shows when the pointer rests on the trigger for delay milliseconds, at once when the trigger is focused from the keyboard, and when a touch is held still on it for half a second. Moving from one tooltip's trigger to another's shows the next at once. The pointer can move onto the tooltip without it closing, and Escape closes it. After a touch-hold it stays for a moment and a half after the finger lifts, or until the next tap, and the click and context menu the hold would cause are swallowed, so holding an icon button to read its tooltip does not press it. A wrapped disabled button still shows its tooltip. Only one tooltip shows at a time.

It floats above the page as a popover in the browser's top layer, so no scrolling or overflow: hidden container clips it. It sits on its placement side of the trigger, flips to the other side when there is no room, and is always kept inside the viewport, with its arrow still pointing at the trigger. It follows the trigger on scroll and resize, and hides once the trigger scrolls out of view. Requires a browser with the Popover API (Chrome/Edge 114+, Firefox 125+, Safari 17+).

For screen readers, the trigger gets the tooltip's text as its aria-label when it has no name of its own (an icon-only button), and as its aria-description otherwise. A label or description the trigger already has is left alone, and the tooltip removes only what it set.

Attributes

text

Observed: true
Default: ""
The tooltip's text, used when there is no slot="content" markup. A tooltip with neither never shows.

for

Observed: true
Default: null
The id of the element the tooltip is for, found in the same document or shadow root as the tooltip. Without it, the tooltip is for the element it wraps. Changing it moves the tooltip to the new element.

placement

Observed: true
Default: "top"
"top", "bottom", "left", or "right" -- the side of the trigger the tooltip is placed on when it fits there.

delay

Observed: true
Default: 400
How long, in milliseconds, the pointer rests on the trigger before the tooltip shows. Keyboard focus and a touch-hold are not delayed by it.

disabled

Observed: true
Default: false
Boolean. The tooltip never shows, and gives its trigger no label or description.

Methods

show() / hide()

Shows the tooltip beside its trigger, or hides it, from code. show() does nothing while the tooltip is disabled or empty.

Getters / Setters

open

get: Whether the tooltip is showing.

text / for / placement / delay / disabled

get/set: Mirror the matching attributes.

GalaxyTooltipController

new GalaxyTooltipController(root) / attach(container, resolve) / detach_listeners() / destroy()

The behavior behind every tooltip, for a component that shows tooltips of its own, as the Table does. It adds one bubble and its styles to root (the component's shadow root), and listens on container. resolve(element) is given the element under the pointer or focus and returns {anchor, content} -- the element to place the bubble beside, and its text or a function that fills the bubble's content element -- or null for none. placement and show_delay are set on the controller; show(anchor, content) and hide() work as on the element.

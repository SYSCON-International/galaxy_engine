Datetime Picker

File: GalaxyDatetimePicker.js
Tag: galaxy-datetime-picker
Extends: GalaxyDatetimePickerBase
A combined date and time picker. A thin subclass of Datetime Picker Base that only passes "datetime" as the mode -- its full API (attributes, popup behavior, value shapes) is documented there. Also used internally by Datetime Range for its start/end fields.

Attributes

None

No attributes of its own -- see Datetime Picker Base for label, layout, time-format, and value.

Methods

None

No methods of its own -- see Datetime Picker Base.

Example


            
        

            let scheduled_for = document.querySelector('#scheduled_for');

            scheduled_for.value = {year: 2026, month: 3, day: 14, hour: 9, minute: 0};

            console.log(scheduled_for.value_dictionary); // {__type__: "datetime", year: 2026, month: 3, day: 14, hour: 9, minute: 0, ...}

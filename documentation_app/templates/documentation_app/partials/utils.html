A utility class for various helper functions, exposed as window.galaxy_utils. Every method is static, so it can also be called directly on the class (GalaxyUtils.debounce(...)) without needing the instance.

Attributes

None

This is a plain utility class -- it has no attributes.

Methods

static get_text_width(text, font = null)

Returns the width of the given text when rendered with the specified font, in pixels. If no font is provided, it measures using the current computed font of document.body.

static debounce(callback, delay, immediate = false)

Wraps callback in a debounced function that only actually runs after delay milliseconds have passed since the last call. If immediate is true, the first call in a burst runs right away (leading edge) and the debounce window afterward simply suppresses further calls until it elapses, instead of the usual trailing-edge behavior.

static closest_through_shadow_roots(element, selector)

The same as the native Element.closest(), but continues searching across shadow-root boundaries by jumping from a shadow root to its host element. This is needed because a shadow-rendered element's ancestor chain stops at its own shadow root -- it does not naturally continue into the host element's ancestor tree, which native closest() alone can't cross. Returns null if nothing matches all the way up.

Getters / Setters

None

This class has no getters/setters -- every method is a plain static function.

Observers

None

This class has no attributes, so there are no attribute observers.

Example


            let width = GalaxyUtils.get_text_width("Hello, world!");

            let handle_resize = GalaxyUtils.debounce(() => {
                console.log("Window resized");
            }, 250);

            window.addEventListener("resize", handle_resize);

            let host_element = GalaxyUtils.closest_through_shadow_roots(some_element_in_a_shadow_root, ".galaxy-form");

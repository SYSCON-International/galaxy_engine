File: GalaxyUtils.js
Tag: N/A
Extends: N/A
A utility class for various helper functions, exposed as window.galaxy_utils. Every method is static, so it can also be called directly on the class (GalaxyUtils.debounce(...)) without needing the instance.

Attributes

None

This is a plain utility class -- it has no attributes.

Methods

static get_text_width(text, font = null)

Returns the width of the given text when rendered with the specified font, in pixels. If no font is provided, it measures using the current computed font of document.body.

static debounce(callback, delay, immediate = false)

Wraps callback in a debounced function that only actually runs after delay milliseconds have passed since the last call. If immediate is true, the first call in a burst runs right away (leading edge) and the debounce window afterward simply suppresses further calls until it elapses, instead of the usual trailing-edge behavior.

static closest_through_shadow_roots(element, selector)

The same as the native Element.closest(), but continues searching across shadow-root boundaries by jumping from a shadow root to its host element. This is needed because a shadow-rendered element's ancestor chain stops at its own shadow root -- it does not naturally continue into the host element's ancestor tree, which native closest() alone can't cross. Returns null if nothing matches all the way up.

static get_ancestors_through_shadow_roots(element)

Every ancestor of element, nearest first, continuing from each shadow root to its host. Form uses it to reveal the panels around an invalid field.

static get_descendants_through_shadow_roots(element)

Every element inside element's light DOM, continuing into the open shadow root of each one found (but not element's own), in document order. Collapse uses it to close floating content inside a closing panel, including fields a form has moved into its own shadow root.

static add_default_css(css_string, style_id)

Adds default CSS for something drawn outside a component's shadow root, such as the datetime picker's popup or the notification container. It is added once (a second call with the same style_id adds nothing), as the first child of the document head, so a page's own stylesheets come later and override it.

static get_safe_link_url(link, source_name)

Returns a link from configuration as written when it is relative or uses http:, https:, mailto: or tel: (SAFE_LINK_PROTOCOLS), and "#" otherwise, with a console warning naming source_name. The scheme is read the way the browser reads it, so " JavaScript:" or "java\tscript:" are caught. Used for every link a nav builds from its config, so a javascript: link cannot run script.

static get_form_owner_element(form)

The element whose attributes configure a form: the galaxy-form for a galaxy-form's internal <form>, and the form itself for a native one. Used to read submit-on-enter.

static get_default_submit_control(form)

A form's default button: its first submit control in tree order that submits this form - a native submit button (a <button> with no type included) or a galaxy-button with submit. A control inside the form that names another form with form="…" is skipped; one outside the form is not found. Returns null when there is none.

static submit_form_implicitly(form)

Submits a form as Enter in one of its fields does, when it has submit-on-enter: activates its default button (a disabled one blocks it), or, with none, calls requestSubmit(). Returns whether it submitted. Called by on_host_keydown().

Getters / Setters

None

This class has no getters/setters -- every method is a plain static function.

Observers

None

This class has no attributes, so there are no attribute observers.

Example


            let width = GalaxyUtils.get_text_width("Hello, world!");

            let handle_resize = GalaxyUtils.debounce(() => {
                console.log("Window resized");
            }, 250);

            window.addEventListener("resize", handle_resize);

            let host_element = GalaxyUtils.closest_through_shadow_roots(some_element_in_a_shadow_root, ".galaxy-form");

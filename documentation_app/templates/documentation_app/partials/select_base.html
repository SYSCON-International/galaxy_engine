Select Base

File: GalaxySelectBase.js
Tag: N/A
Extends: GalaxyInputBase

The base class for the GalaxySelect and GalaxyMultiSelect custom elements.

It handles the following:
  • Observing and parsing the options-data attribute.
  • A shared search/filter system (if search is enabled).
  • The open attribute, toggling dropdown logic.
  • Closing other open galaxy selects.
  • Basic form association + validation stubs.

Attributes

Observed: false
Default: false

Methods

Handles the built-in click event for the button. If the button has confirmation enabled, it will show a confirmation modal. It will also update the modal's title, body, and button texts based on the component's attributes.

Getters / Setters

get: Gets the text content of the button.
set: Sets the text content of the button to the specified value.

Select Base

File: GalaxySelectBase.js
Tag: N/A
Extends: GalaxyInputBase

The base class for the GalaxySelect and GalaxyMultiSelect custom elements.

It handles the following:
  • Observing and parsing the options-data attribute.
  • A shared search/filter system (if search is enabled).
  • The open attribute, toggling dropdown logic.
  • Closing other open galaxy selects.
  • Basic form association + validation stubs.
  • Pool management for options list virtualization

Attributes

open

Observed: true
Default: false
Controls the open/closed state of the select dropdown.

search-enabled

Observed: true
Default: false

instant-validation

Observed: false
Default: false
If set to true, the select will validate its value immediately when it changes. Otherwise, validation will only occur when the form is submitted.

collapsible-groups

Observed: true
Default: false
If set to true, option groups can be collapsed/expanded. This is useful for large lists of options grouped by categories.

options-size

Observed: true
Default: 5
Controls the number of options displayed in the dropdown before scrolling is required. This can be adjusted to fit the design needs of your application.

selected (option elements)

Observed: false
Default: false
Indicates if the option is the selected option in the dropdown.

option-group (option elements)

Observed: false
Default: false
Indicates if the option is a group header in the dropdown. This is used to visually separate options into categories.

Methods

normalize_option_data(option_data)

Normalizes the provided options data into a standard format.

This method is used internally to ensure that the options data is in a consistent format before being set on the select element.

handle_document_click(event)

If the document is clicked outside of the select this will close the dropdown.

handle_window_scroll_or_resize(event)

If the window is scrolled or resized this will handle repositioning the dropdown.

initialize_selected_options()

This method will initialize the selected options based on the current value of the select.

close_other_selects()

This method close the dropdowns of all other galaxy selects.

open_options()

This method opens the dropdown options. It will also handle smart positioning and close other open galaxy selects.

close_options()

This method closes the dropdown options. It will also handle closing other open galaxy selects.

position_options()

This method repositions the dropdown options based on the current position of the select element. It is called when the window is scrolled or resized to ensure the dropdown remains visible.

input_on_click()

This method is called when the select input is clicked and is overridden to handle opening the dropdown.

build_flat_data(options, indent = 0)

Builds a flat data structure for the options to be used in the virtualized list.

create_or_resize_option_elements_pool(count)

Creates or resizes the pool of option elements used for virtualization. This is used to efficiently manage the DOM elements for large lists of options.

render_options(options = null)

Renders the options in the dropdown.

If options is provided, it will use that data to render the options. Otherwise, it will use the current options attribute value.

update_visible_rows()

Updates the visible rows in the dropdown based on the current scroll position. This is used for virtualization to only render the options that are currently visible.

update_option_element(option_element, option_icons_container_element, option_data)

Updates the provided option element with the data from option_data. This includes setting the text, icons, and selected state.

update_icons_element(icons_element, option_data)

Updates the icons element with the icons from option_data. This is used to display any icons associated with the option.

update_option_element_width()

Updates the width of the option elements to match the width of the select input. This ensures that the options are displayed correctly in the dropdown.

update_right_icon_spacing()

Updates the spacing for the right icon in the select input. This is used to ensure that the right icon does not overlap the scrollbar in the dropdown.

toggle_group(option_data)

Toggles the visibility of a group of options in the dropdown. This is used when the collapsible-groups attribute is set to true.

find_group(value, options_data = null)

Finds the group that contains the option with the specified value.

find_option(value, options_data = null)

Finds the option with the specified value in the options data. This is used to get the option data for the selected value.

search_data(query, data_array)

Searches the provided data_array for options that match the query. This is used to filter the options in the dropdown when search-enabled is set to true.

add_search_clear_button_and_down_arrow()

Will add a clear button to the search input and a down arrow to the select.

clear_search(event)

Clears the search input and resets the options in the dropdown. This is used when the clear button is clicked in the search input.

set_input_placeholder()

Will set the input placeholder based on the search-enabled attribute.

option_on_click(option_element, option_icons_container_element, option_data)

This method is called when an option is clicked in the dropdown. This should be overridden in the child classes to handle the selection logic.

on_input_event(event)

This method is called when an input event occurs on the select input.

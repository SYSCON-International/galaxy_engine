Sidebar

File: GalaxySidebar.js
Tag: galaxy-sidebar
Extends: GalaxyNavbarBase
A vertical sidebar navigation component: a collapsible icon-only rail (its state remembered where remember says), nested-children dropdowns, icon-fallback badges for unicon items, and current-page highlighting. Navbar is the horizontal counterpart -- both extend Navbar Base, which documents the shared theme/config attributes and dropdown behavior.

Attributes

collapsed

Observed: true
Default: false
Collapses the rail down to an icon-only width. Toggled by the built-in collapse/expand button, and its state is remembered where remember says (see persist_collapsed_state()) so it's kept across page loads.

remember

Observed: false
Default: local
Where the collapsed state is remembered, under get_collapse_storage_key(): local keeps it in the browser's localStorage; session keeps it in the app's session through window.galaxy_session_store ({get(key), set(key, value)}, registered by the app, as for Tabs); and none keeps it nowhere. An unrecognized value is local. A state the session store returns after the user has already toggled the rail is ignored.

Methods

async post_on_create()

Restores any previously-persisted collapsed state. Implemented as post_on_create rather than overriding on_create because Navbar Base's own on_create is a class-field arrow function (assigned per-instance, not on the prototype), so super.on_create() isn't reachable here -- post_on_create is the hook GalaxyHTMLComponentBase's lifecycle already runs immediately after on_create for exactly this reason.

get_collapse_storage_key()

Builds the key used to remember the collapsed state, scoped to this element's id (falling back to "default") so multiple sidebars on one page don't clobber each other's stored state.

persist_collapsed_state()

Writes the current collapsed state where remember says, under get_collapse_storage_key()'s key, so the rail remembers its state across page loads. Called automatically whenever collapsed changes. A storage failure only warns via console.warn: localStorage disabled or full, or a session store that throws or answers with a rejected promise. A value equal to the one last stored or read is not written again, so restoring the remembered state does not write it straight back.

async restore_collapsed_state()

Reads a previously-persisted collapsed state from where remember says, if any exists, and applies it. Called once from post_on_create().

build_collapse_toggle()

Overrides Navbar Base's no-op to build the collapse/expand toggle button (unless the config sets collapsible: false), and to update it in place any time collapsed changes so its icon/aria-label stay in sync. It is the same button throughout, so a toggle pressed from the keyboard keeps focus.

on_collapse_toggle_click()

Flips collapsed when the built-in toggle button is clicked.

Getters / Setters

static layout_option

get: Returns "vertical". See Navbar Base's layout getter.

collapsed

get: Gets the collapsed state of the sidebar.
set: Sets or removes the collapsed attribute.

default_config

get: Overrides Navbar Base's default config, adding collapsible: true.

Observers

handle_observed_collapsed()

Persists the new collapsed state and rebuilds the collapse toggle button so its icon/label stay in sync.

Example


            
        

            let sidebar = document.querySelector('#main_sidebar');

            sidebar.config = {
                collapsible: true,
                brand: {name: "GX", link: "/", should_show: true},
                navigation: [
                    {label: "Home", icon: "fas fa-house", link: "/"},
                    {label: "Analytics", link: "/analytics"},
                    {
                        label: "Team",
                        children: [
                            {label: "Members", link: "/team/members"},
                            {label: "Invite", link: "/team/invite"}
                        ]
                    },
                    {label: "General", is_heading: true},
                    {label: "Preferences", icon: "fas fa-sliders", link: "/settings/preferences"}
                ]
            };

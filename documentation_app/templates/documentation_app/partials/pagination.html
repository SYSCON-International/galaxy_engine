Pagination

File: GalaxyPagination.js
Tag: galaxy-pagination
Extends: GalaxyHTMLComponentBase
Controls for moving through a paged list: first and previous buttons, the page numbers, a typed "Page n / N", next and last buttons, and a "Rows per page" picker. The arrows are icon-only, with tooltips, and are disabled at the ends of the range.

The page numbers always show the first and last pages and the current page with sibling-count pages either side, with "…" where pages are skipped -- 1 … 9 10 11 … 20. Near either end the window widens toward the middle instead, so the row keeps the same length and the controls do not shift as the page changes. In a narrow container the numbers hide, leaving the arrows, the typed page, and the picker. The typed page is committed on Enter or when the field is left, clamped to the pages there are; Escape, an empty field, or a non-number puts back the current page.

On its own, it is driven by page_change: the page fetches and shows the page asked for -- typically from the server -- and keeps total-items (or page-count) up to date. With for, it pages a Table in the browser instead.

Attributes

page

Observed: true
Default: 1
The current page, 1-based, clamped to the pages there are (0 when there are none).

page-count

Observed: true
Default: 1
How many pages there are. Ignored when total-items is set or a table is linked.

total-items

Observed: true
Default: null
How many items there are in all. When set, the page count is worked out from it and page-size, so a new page size changes the page count too.

page-size / page-size-options

Observed: true
Default: 25 / 10, 25, 50, 100
How many items a page shows, and the sizes the "Rows per page" picker offers (a JSON array or a comma-separated list; the current size is always offered). Picking a new size moves to the page that holds the first item shown before.

sibling-count

Observed: true
Default: 1
How many page numbers show on each side of the current page.

hide-page-size / disabled

Observed: true
Default: false
Booleans hiding the "Rows per page" picker, and disabling every control (while a page loads, for one).

for

Observed: true
Default: null
The id of a Table (or Editable Table) to page in the browser, found in the same document or shadow root. The pagination sets the table's page-size and page, takes the page count from its rows, and follows it when the table moves itself -- an editable table adding a row on a later page -- without dispatching page_change, since that move was not made on the pagination. page-count and total-items are ignored while linked, and removing for leaves the table showing every row. A Sortable List does not page. A table added after the pagination is linked when it connects (see add_connection_listener()), so the two can be added in either order. When a page number is pressed, the rebuilt page buttons give keyboard focus to the same page's button.

Methods

set_page(page)

Moves to a page, clamped to the pages there are, without dispatching page_change.

GalaxyPagination.get_page_items(page, page_count, sibling_count)

Static. The page numbers to show, with "ellipsis" where pages are skipped.

Getters / Setters

page / page_count / page_size / page_size_options / total_items / sibling_count / hide_page_size / disabled / for

get/set: Mirror the matching attributes; page and page_count read back as worked out. None dispatches page_change.

Events

page_change

Bubbling, dispatched when a user's button, typed page, or page size changes the page or the page size: {page, previous_page, page_size, previous_page_size}.

Example


            

            
            
        

            let pagination = document.getElementById('job_pages');

            pagination.addEventListener('page_change', async (event) => {
                pagination.disabled = true;
                let response = await fetch_jobs(event.detail.page, event.detail.page_size);
                job_table.rows = response.jobs;
                pagination.total_items = response.total;
                pagination.disabled = false;
            });

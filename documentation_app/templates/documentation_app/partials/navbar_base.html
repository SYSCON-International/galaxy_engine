Navbar Base

File: GalaxyNavbarBase.js
Tag: N/A -- abstract, never registered as its own custom element
Extends: GalaxyHTMLComponentBase
The shared base for Galaxy's navigation components: config/theme handling, dropdown interaction (hover, click/tap, keyboard, outside-click/Escape dismissal), nav item/icon building, and current-page highlighting. Never registered as a custom element itself -- Navbar (horizontal) and Sidebar (vertical/collapsible) extend it with the pieces specific to their own layout.

Attributes

theme

Observed: true
Default: light
The color theme to apply. Accepts either a built-in mode name (light or dark), or a JSON string of a custom theme object ({nav_bg, nav_text, nav_border, link_bg, link_text, link_hover_bg, link_hover_text, font_family}) -- e.g. pass JSON.stringify(my_theme). Falls back to the config's own theme (or light) if not explicitly set.

config

Observed: true
Default: null (falls back to default_config)
A JSON string (or, via the config property, a plain object) describing the nav: {brand: {name, logo_url, link, tagline, should_show}, theme, navigation: [{label, icon, link, section, children, multi_column, columns, is_heading, type: "button", onclick}]}. Each navigation entry's section is "left" (default), "center", or "right".

disable-hover

Observed: false
Default: false
When present, dropdowns only open via click/tap or keyboard activation instead of also opening on mouse hover.

Methods

async attribute_changed_callback(name, old_value, new_value)

Looks up and calls the matching handler from attribute_handlers. A subclass that observes additional attributes (e.g. Sidebar's collapsed) extends that map via ...super.attribute_handlers rather than overriding this method.

apply_config(value)

Parses value (a JSON string or plain object) into the active config and rebuilds the nav if it's already built. Falls back to default_config with a console warning if value is invalid. Shared by the config property setter and the config attribute reaction.

attach_nav_event_listeners()

Wires up the hover/click/keyboard dropdown handlers on the nav, plus document-level click/Escape dismissal. Called once per element instance, from on_create().

on_nav_mouse_over(event)

Opens a dropdown-bearing nav item's dropdown on hover, unless disable_hover is set.

on_nav_mouse_out(event)

Closes a dropdown-bearing nav item's dropdown once the mouse truly leaves that item (not merely moving into its own dropdown panel), unless disable_hover is set.

on_nav_item_click(event)

Toggles a dropdown-bearing nav item's dropdown open/closed on click or tap. Always active regardless of disable-hover, so touch and keyboard users can always reach dropdown content. Prevents navigation for placeholder (href="#") links.

on_nav_item_keydown(event)

Handles Space-key activation of a dropdown trigger (Enter is already handled natively as a click on anchors).

on_document_click(event)

Closes every open dropdown belonging to this nav when the user clicks anywhere outside of it (uses event.composedPath() so clicks inside the shadow DOM are correctly detected as "inside").

on_document_keydown(event)

Closes any open dropdown belonging to this nav on Escape and returns focus to its trigger link.

open_dropdown(li)

Opens a single nav item's dropdown (sets the open attribute on its <li> and aria-expanded="true" on its link).

close_dropdown(li)

Closes a single nav item's dropdown, along with any of its own nested open dropdowns.

toggle_dropdown(li)

Toggles a single nav item's dropdown. Closes every other open dropdown first, so click/tap interaction behaves like an accordion.

close_all_dropdowns()

Closes every currently-open dropdown in this nav.

add_theme_css()

Applies the current theme as CSS custom properties directly on the host element, and determines dropdown positioning (above/below for a horizontal nav, left/right for a vertical one) based on the element's position in the viewport. Called whenever theme changes and once during on_create().

build_brand_element(brand)

Builds the brand block (logo/name/tagline, linking home) from config.brand. Built with DOM APIs rather than an HTML template string, since brand is config-supplied data (not necessarily developer-authored) and parsing it as markup would be a stored-XSS hole.

async build_nav_sections()

Clears and rebuilds the left/center/right sections (and brand block) from the active config. Called once during on_create() and again any time the config is replaced.

build_collapse_toggle()

No-op in the base class -- only Sidebar has a collapsible rail, and overrides this to build it.

mark_active_navigation_items()

Marks the nav item(s) whose link matches the current page's path with aria-current="page" and an active class, so the current page is highlighted with no configuration required. Placeholder (href="#") links are never matched.

create_nav_button(item)

Builds a <button>-based nav entry for a config item with type: "button" (used for actions like "Sign Out" that don't navigate), wiring up its onclick handler.

build_item_icon(item, is_top_level)

Builds a nav item's icon element from item.icon. If a top-level item has no icon, falls back to a single-letter badge (the label's first character) so the item still reads correctly when a collapsed Sidebar rail shrinks to icon-only width; nested/column items with no icon get no icon element at all.

async build_nav_item(item, is_top_level = true)

Builds a single navigation item element, including headings (is_heading), multi-column dropdowns (multi_column + columns), and nested single-column dropdowns (children, built recursively).

async on_create()

Resolves the initial config/theme (reading the config attribute directly rather than trusting attribute-reaction timing, since attributeChangedCallback reactions can race connectedCallback), applies the theme, builds the nav shell once, and calls build_nav_sections(). See also GalaxyHTMLComponentBase.

async on_destroy()

Removes the document-level click/keydown listeners added by attach_nav_event_listeners(). See also GalaxyHTMLComponentBase.

Getters / Setters

config

get: Gets the currently-applied config object.
set: Parses and applies a new config (via apply_config()). Deliberately does not reflect back onto the config attribute -- doing so would make every property assignment also re-trigger the (async) attribute reaction, running a second, overlapping build_nav_sections() concurrently with the first.

theme

get: Gets the theme attribute's raw value.
set: Sets the theme attribute and re-applies the theme CSS; setting a falsy value removes the attribute instead.

layout

get: The fixed layout orientation ("horizontal" or "vertical") for this concrete nav type, from its layout_option static getter (e.g. Navbar returns horizontal, Sidebar returns vertical). Unlike theme, this never changes at runtime -- it has no setter and is not attribute-backed.

disable_hover

get: Gets the disable-hover state of the nav.
set: Sets or removes the disable-hover attribute.

default_config

get: The config used when no config attribute/property has been supplied. Subclasses override to layer on their own defaults (e.g. Sidebar adds collapsible: true).

attribute_handlers

get: The attribute-name -> handler lookup consumed by attribute_changed_callback(). A subclass that observes more attributes extends this map with ...super.attribute_handlers.

Observers

handle_observed_theme(new_value)

Re-applies the theme CSS whenever the theme attribute changes (add_theme_css() falls back to the default theme when theme is empty, so this is always safe to call).

handle_observed_config(new_value)

Applies a new config when the config attribute is set directly (e.g. el.setAttribute('config', json)) rather than through the config property setter. No-ops during the very first load, since on_create() already read the attribute directly.

Example

GalaxyNavbarBase is abstract and never used directly -- see Navbar or Sidebar for a real element. Both share this config shape: 

            navbar.config = {
                brand: {name: "Galaxy Engine", logo_url: "/logo.svg", link: "/", tagline: "The future of frontend", should_show: true},
                theme: "dark",
                navigation: [
                    {label: "Dashboard", icon: "fas fa-home", link: "/dashboard"},
                    {
                        label: "Settings",
                        icon: "fas fa-cogs",
                        children: [
                            {label: "Users", link: "/settings/users"},
                            {label: "Preferences", link: "/settings/preferences"}
                        ]
                    },
                    {
                        type: "button",
                        label: "Sign Out",
                        section: "right",
                        onclick: () => console.log("Sign out clicked")
                    }
                ]
            };

Form

File: GalaxyForm.js
Tag: galaxy-form
Extends: GalaxyHTMLComponentBase

The galaxy-form component is a custom form element that extends the functionality of the base component. It provides a structured way to create forms using the Galaxy framework, allowing developers to easily manage form inputs, validation, and submission.

Note about initialization:
Several steps are taken when a form is initialized:

  1. Set the form's action, method, enctype, novalidate, and target attributes.
  2. Move all direct child nodes of galaxy-form into the form
  3. Run pre_on_create, on_create, and post_on_create for all Galaxy children. This is done after moving the children to prevent the children from running these methods twice. 1st when they are created and 2nd when the form is created and the children are moved to the form.

Attributes

action

Observed: true
Default: ""

The URL to which the form data will be submitted. If not specified, the form will submit to the current page.

method

Observed: true
Default: "GET"

The HTTP method to use when submitting the form. Common values are "GET" and "POST". If not specified, the default is "GET".

enctype

Observed: true
Default: ""

The encoding type for the form data when it is submitted. This is important for file uploads and other types of data. Common values include "application/x-www-form-urlencoded", "multipart/form-data", and "text/plain". If not specified, the default is "application/x-www-form-urlencoded".

novalidate

Observed: true
Default: false

When set to true, the form will not perform any validation on the input fields before submission. This can be useful for forms that require custom validation logic or when you want to handle validation manually. If not specified, the default is false, meaning the form will validate inputs according to HTML5 standards.

target

Observed: true
Default: false

Specifies where to display the response after submitting the form. This can be a named iframe or a window. If not specified, the response will be displayed in the same window.

instant-validation

Observed: false
Default: false

When set to true, the form will validate inputs immediately as the user types or interacts with the form fields. This provides instant feedback to the user about the validity of their input. If not specified, the default is false, meaning validation will occur only when the form is submitted.

Methods

on_form_submit(event)

Handles the form submission event. This method is called when the form is submitted, either by clicking a submit button or pressing Enter in an input field. It can be used to perform custom actions before the form is actually submitted, such as validation or data manipulation.

validate(scroll_to_first_invalid = true)

Validates the form inputs according to HTML5 standards or custom validation logic. If any input is invalid, it will return false and optionally scroll to the first invalid input if scroll_to_first_invalid is true. If all inputs are valid, it returns true.

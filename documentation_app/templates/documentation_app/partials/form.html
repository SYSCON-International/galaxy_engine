Form

File: GalaxyForm.js
Tag: galaxy-form
Extends: GalaxyComponentBase

Attributes

Observed: false
Default: false

Methods

Handles the built-in click event for the button. If the button has confirmation enabled, it will show a confirmation modal. It will also update the modal's title, body, and button texts based on the component's attributes.

Getters / Setters

get: Gets the text content of the button.
set: Sets the text content of the button to the specified value.

Select

File: GalaxySelect.js
Tag: galaxy-select
Extends: GalaxySelectBase
A custom select element that extends the GalaxySelectBase class.

Attributes

anchor_dropdown

Observed: true
Default: false
If set to true, the dropdown will be anchored to the select element keeping it open.

Example


            
        

            let select = document.querySelector('galaxy-select');

            select.options = [
                { value: 'option1', text: 'Option 1' },
                { value: 'option2', text: 'Option 2' },
                { value: 'option3', text: 'Option 3' }
            ];

            select.value = 'option2'; // Set the selected value

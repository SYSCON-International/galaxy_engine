Select

File: GalaxySelect.js
Tag: galaxy-select
Extends: GalaxySelectBase
A custom select element that extends the GalaxySelectBase class.

Its dropdown floats over the page like a native select's list: the options element is shown as a manual popover in the browser's top layer, so it sits above all other content, is not clipped by any ancestor's overflow or transform, and does not push the content below it down. It opens below the input, or above it when there is not room below and there is more above, and follows the input on scroll and resize (see position_options()). With anchor_dropdown, the list sits in the page instead. Requires a browser with the Popover API (Chrome/Edge 114+, Firefox 125+, Safari 17+).

Attributes

anchor_dropdown

Observed: true
Default: false
If set to true, the dropdown will be anchored to the select element keeping it open, as part of the page rather than a floating popover. Toggling it switches between the two at any time.

Example


            
        

            let select = document.querySelector('galaxy-select');

            select.options = [
                { value: 'option1', text: 'Option 1' },
                { value: 'option2', text: 'Option 2' },
                { value: 'option3', text: 'Option 3' }
            ];

            select.value = 'option2'; // Set the selected value

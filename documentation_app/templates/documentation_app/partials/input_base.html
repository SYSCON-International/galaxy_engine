Input Base

File: GalaxyInputBase.js
Tag: N/A
Extends: GalaxyHTMLComponentBase
A parent class for all input types including select, input (text, number, float, etc..), and textarea.

Its shadow root is created with delegatesFocus (see shadow_root_options), so the inner field is the element's only tab stop, while element.focus() and clicks on the label area still move focus into the field. The label/input markup is rebuilt on every create and removed on every destroy (see post_on_destroy()), so a subclass that inserts its own markup inside it -- a select's options, a duration input's fields -- needs no cleanup of its own for a reconnect to render cleanly.

Attributes

disabled

Observed: true
Default: false
Indicates whether the input element is disabled. When set to true, the input will not be editable and will not submit its value.

label

Observed: true
Default: ""
The label for the input element. This is displayed next to the input field and can be used to describe the purpose of the input.

name

Observed: true
Default: ""
The name attribute of the input element. This is used to identify the input when submitting a form.

readonly

Observed: true
Default: false
Indicates whether the input element is read-only. When set to true, the input cannot be modified by the user but can still be submitted.

required

Observed: true
Default: false
Indicates whether the input element is required. When set to true, the form cannot be submitted unless this input has a value and passes validation.

value

Observed: true
Default: ""
The value of the input element. This is the data that will be submitted with the form when it is submitted and also the value that is displayed in the input field.

data-property

Observed: false
Default: null
Not supported on a Galaxy input: it logs a console warning and does nothing. data-property binds plain elements (a div, a native input) to the State Manager; a Galaxy input binds through property-name.

property-name

Observed: false
Default: null
Binds the input two-way to this property in the State Manager: the user's changes are written to the property (through write_state_value()), and a change from anywhere else -- a script, or another input with the same property-name -- is applied to the input (through apply_state_value()), without a change event. When the input is created, an existing property's value wins over the input's own; a new property is seeded with the input's value. Plain elements with a data-property of the same name are updated too.

placeholder

Observed: false
Default: ""
The placeholder text for the input element. This text is displayed in the input field when it is empty and can be used to provide a hint to the user about what to enter.

Methods

connect_state_binding()

Run from post_on_create(), after the subclass's own create: binds the input to its property-name, adopting an existing state value or seeding a new one. Undone in post_on_destroy() and redone on reconnect.

write_state_value(value)

Writes a value to the input's property-name, updating everything else bound to it but not this input. The one path every subclass reports a value change through. Does nothing until the input is bound, so values reported during create cannot overwrite a state value the input is about to adopt.

apply_state_value(value)

Applies a state value written elsewhere by setting value, so each subclass's own setter interprets it. Override when the setter cannot take the state's value as-is -- Select Base JSON-encodes its array.

on_input_event(event)

Event handler for user typing that will do the following:
  1. Set the value of the galaxy element, the State Manager property if it is bound (see write_state_value()), and the form value.
  2. Validate the input if it is required and instant validation is enabled on the parent Form.
  3. Call on_input() for child classes to implement.

on_change_event(event)

Event handler for user changing the input that will do the following:
  1. Set the value of the galaxy element, the State Manager property if it is bound (see write_state_value()), and the form value.
  2. Validate the input if it is required and instant validation is enabled on the parent Form.
  3. Call on_input() for child classes to implement.

show_label()

Shows the label for the input element.

hide_label()

Hides the label for the input element.

validate()

Checks if there are any errors on the input element and will set the validity of the input element. When required, uses is_value_empty()/required_error_message (rather than a hardcoded value === "" check) so subclasses whose value isn't a plain string can still validate correctly.

get_validation_errors()

Returns an array of validation errors for the input element. This function is overridden in child classes to provide specific validation messages. These messages are used by validate() to set the validity of the input element.

is_value_empty(value)

Whether value counts as "no value entered" for required validation. Defaults to value === "" -- override for a value type other than a plain string (e.g. Select Base overrides this to check for an empty array, since a select's value is always an array).

required_error_message

The message shown when a required field is empty (per is_value_empty()). Defaults to "Please enter a value." -- override for a more specific message (e.g. Select Base uses "Please select an option.").

formResetCallback()

Web Components form-association lifecycle hook: called when the owning form is reset. Restores the value the element had when it was created (its initial value attribute, captured once in pre_on_create(), or empty).

formDisabledCallback(is_disabled)

Web Components form-association lifecycle hook: called when the element becomes disabled or enabled as a result of an ancestor <fieldset> being disabled, rather than its own disabled attribute. Keeps disabled in sync.

formStateRestoreCallback(state)

Web Components form-association lifecycle hook: called when the browser restores previously-submitted state (e.g. after a reload or back/forward navigation). Applies state as the new value when it's a string.

on_input(event)

This method is called when the input event is triggered. It is intended to be overridden by child classes to implement specific behavior when the input changes. Called at the end of on_input_event().

on_change(event)

This method is called when the change event is triggered. It is intended to be overridden by child classes to implement specific behavior when the input changes. Called at the end of on_change_event().

post_on_destroy()

Removes the label/input markup pre_on_create() built, after the subclass's on_destroy() has run its own cleanup. Without it, a reconnected input would show a second copy of its field.

static shadow_root_options

Returns {delegatesFocus: true} -- see GalaxyHTMLComponentBase.

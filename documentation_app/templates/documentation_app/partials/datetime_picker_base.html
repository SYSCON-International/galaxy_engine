Datetime Picker Base

File: GalaxyDatetimePickerBase.js
Tag: N/A -- never registered directly
Extends: GalaxyInputBase
The shared implementation behind Date Picker, Time Picker, and Datetime Picker -- a text input that shows a calendar/time popup on focus or click, and keeps an internal ISO-formatted value (YYYY-MM-DD, HH:mm, or YYYY-MM-DDTHH:mm) in sync with a locale-formatted display string. The concrete subclasses only pass their mode ("date"/"time"/"datetime") to the constructor -- every attribute and method here applies to all three.

Attributes

label

Observed: true
Default: ""
See Input Base.

layout

Observed: true
Default: "horizontal"
"horizontal" or "vertical" label layout.

time-format

Observed: true
Default: "12"
"12" or "24" hour time display/entry format. Used by Time Picker and Datetime Picker (ignored by Date Picker, which has no time portion).

value

Observed: true
Default: ""
The current value. Accepts a JSON string, a plain ISO string in the mode's own format, a plain object ({year, month, day, hour, minute}), or a moment.js-like object -- see normalize_value().

Methods

set_event_listeners()

Wires up the input's focus/click listeners (to show the popup) and a document-level click listener (to hide it).

format_for_display(iso_string)

Formats an internal ISO string for display, using the browser's locale formatting and (for time/datetime) time-format.

parse_from_display(display_value)

Parses a display string back into the internal ISO string.

validate_format()

Validates the input's current text against the mode's expected format, toggling an error class accordingly, and dispatches an input_validated custom event (detail: {picker: this}) on both the host and the internal input element.

get_validation_errors(value)

Returns ["Invalid date/time format."] when validate_format() fails, otherwise [].

async show_popup(event)

Shows the calendar/time popup on focus or click, creating it (via create_popup()) the first time.

hide_popup(event)

Destroys the popup when a click occurs outside of it and outside the input. Uses event.composedPath() rather than event.target, since a composed event crossing a shadow boundary is retargeted to the enclosing shadow host -- which would otherwise misreport every click as landing on e.g. an enclosing Form instead of this picker.

async create_popup()

Builds the popup: a calendar grid (for date/datetime mode) and/or hour/minute inputs plus an AM/PM select (for time/datetime mode, when time-format is "12").

build_calendar(date)

(Re)builds the calendar grid for the month/year of date, marking the currently-selected day if any.

sync_popup_from_input()

Synchronizes the popup's calendar/time inputs with the main input's current value, and re-validates.

destroy_popup()

Removes the popup from the DOM and clears its reference.

convert_datetime_value_to_dictionary(iso_string)

Converts an internal ISO string into the structured dictionary returned by value_dictionary.

normalize_value(new_value)

Normalizes an incoming value of any accepted shape (a JSON string, a plain ISO string in the mode's format, a plain {year, month, day, hour, minute} object, or a moment.js-like object) into the internal ISO string, or "" if it can't be recognized.

on_input(event)

See GalaxyInputBase. Here, re-synchronizes the popup from the input's new text.

Getters / Setters

layout

get: Gets the layout attribute ("horizontal" by default).
set: Sets the layout attribute.

time_format

get: Gets the time-format attribute ("12" by default).
set: Sets the time-format attribute.

value

set: Normalizes and applies a new value (see normalize_value()), updates the display text, and validates.
Note: this class only overrides the setter. The value getter is inherited from Input Base and returns its internal _value field, which this override chain never updates -- so reading .value back does not reliably reflect the picker's current value. Use value_dictionary instead to read the current value.

value_dictionary

get: The current value as a structured dictionary: {__type__: mode, year, month, day, hour, minute, second, microsecond, tzinfo}. Fields not applicable to the current mode are null; tzinfo is the page's TIME_ZONE global if present, otherwise the browser's resolved time zone.

is_valid

get: Gets the current validity state, as last computed by validate_format().
set: Sets the validity state directly.

Observers

handle_observed_confirm_label_text(new_value)

Updates the visible label text when the label attribute changes.

Example

GalaxyDatetimePickerBase is never used directly -- see Date Picker, Time Picker, or Datetime Picker for a real element.

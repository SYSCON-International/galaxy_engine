Duration Utils

File: GalaxyDurationUtils.js
Tag: N/A
Extends: N/A
Pure, side-effect-free unit-conversion, decomposition, normalization, and formatting math shared by Duration Input and Duration Display. Every method is static, matching the shape of Utils -- this class holds no DOM or per-instance state. Methods throw DurationValidationError (an Error subclass exported from this file) on a malformed argument (unsupported unit, non-finite/negative value, unsupported precision_mode, or an empty/invalid visible_units list) -- component code should validate attribute-sourced configuration before calling into these methods rather than letting this escape a custom element lifecycle callback uncaught.

Attributes

MICROSECONDS_PER_UNIT

Module-level export (not a class member): {microseconds, milliseconds, seconds, minutes, hours, days} -> microseconds-per-unit. All conversions pass through this canonical integer-microsecond value so unit conversion involving very small units never accumulates floating-point rounding error.

SOURCE_UNITS

Module-level export: ["microseconds", "milliseconds", "seconds", "minutes", "hours", "days"] -- units a scalar duration value may be received in or converted out to.

DISPLAY_UNIT_ORDER

Module-level export: ["days", "hours", "minutes", "seconds"] -- the units Duration Input/ Duration Display can render, in canonical largest-to-smallest rendering order regardless of what order visible_units lists them in.

DEFAULT_UNIT_LABELS / DEFAULT_SHORT_UNIT_LABELS / DEFAULT_LONG_UNIT_LABELS

Module-level exports of the default per-unit label text: long-form labels (used as Duration Input's visible <label>/aria-label and its unit-labels fallback), short abbreviations (Duration Display's "short" format), and singular/plural pairs (Duration Display's "long" format).

DEFAULT_TRUNCATION_WARNING_TEMPLATE

Module-level export: the default template for Duration Input's received-value truncation warning. Its four %s placeholders are filled, in order, with: original value, unit, remainder value, unit.

DurationValidationError

Module-level export: the Error subclass every method below throws on a malformed argument.

Methods

static is_supported_unit(unit)

Returns true if unit is a supported source/output unit (one of SOURCE_UNITS).

static is_supported_display_unit(unit)

Returns true if unit is a supported visible/display unit (days/hours/minutes/seconds).

static to_microseconds(value, unit)

Converts a scalar duration value (may be fractional, e.g. 1.5 hours) expressed in unit into canonical integer microseconds, rounded to remove floating-point dust.

static from_microseconds(total_microseconds, unit)

Converts canonical integer microseconds into a scalar value expressed in unit. The result may be fractional when unit doesn't evenly divide total_microseconds -- that's a correct conversion, not an error; round it yourself if you need a whole number.

static get_visible_unit_order(visible_units)

Reduces an arbitrary visible_units configuration to the canonical days-to-seconds rendering order, deduplicated, containing only recognized display units.

static decompose(total_microseconds, visible_units)

Decomposes canonical integer microseconds into the configured visible unit fields, returning {parts, original_microseconds, represented_microseconds, remainder_microseconds, was_truncated}. The highest configured unit absorbs any amount a smaller field set couldn't hold (e.g. decomposing into hours/minutes only never loses whole days -- they show up as extra hours). Any amount finer than the smallest configured unit can't be represented and is reported separately as remainder_microseconds/was_truncated rather than silently dropped.

static compose(parts)

Recombines a set of duration field values (e.g. {hours: 1, minutes: 30}) back into canonical integer microseconds. Field values are treated at face value -- a field holding more than its "natural" range (e.g. {minutes: 75}) still contributes exactly that many minutes' worth of microseconds, which is what makes normalize() correct.

static normalize(parts, visible_units)

Redistributes overflow across the configured visible fields (e.g. {minutes: 75} with hours+minutes visible becomes {hours: 1, minutes: 15}). The highest configured field absorbs whatever a higher field would otherwise have held, so {hours: 49} with only hours/minutes visible legitimately stays {hours: 49}.

static natural_range_for_unit(unit, visible_units)

Returns the natural editing range {min, max} for a single visible field, given the full set of visible fields. A field with no larger configured field above it (i.e. it's the highest visible unit) has max: null (unbounded), since there's nowhere for overflow above it to go.

static apply_precision(total_microseconds, visible_units, precision_mode, fraction_digits = 0)

Applies a Duration Display smallest-unit precision policy to a decomposed duration, returning {parts, fractional_smallest_unit_value}. precision_mode is one of: "truncate" (the smallest visible unit shows its whole-number value; anything finer is dropped), "round_up" (if any amount finer than the smallest visible unit exists, its value is incremented by one, cascading into larger visible units as needed -- e.g. 59 -> 60 minutes becomes 1 hour 0 minutes when hours is visible), or "fraction" (the smallest visible unit's value is fractional, rounded to fraction_digits).

static is_plural_count(count)

Returns true if count should use the plural form of a unit label (i.e. count !== 1).

static format_message(template, ...values)

Substitutes "%s" placeholders in template with values, in order. Used for the configurable, localizable truncation warning message.

static parse_json_attribute(raw_value, default_value, component_name, attribute_name)

Parses a JSON-valued attribute (an array or object) from its raw string value, falling back to default_value and warning (via console.warn, including component_name/attribute_name in the message) on malformed JSON.

Getters / Setters

None

This class has no getters/setters -- every method is a plain static function.

Observers

None

This class has no attributes, so there are no attribute observers.

Example


            let total_microseconds = GalaxyDurationUtils.to_microseconds(90, "minutes");

            let decomposed = GalaxyDurationUtils.decompose(total_microseconds, ["hours", "minutes"]);
            // decomposed.parts -> {hours: 1, minutes: 30}

            let normalized = GalaxyDurationUtils.normalize({minutes: 75}, ["hours", "minutes"]);
            // normalized -> {hours: 1, minutes: 15}

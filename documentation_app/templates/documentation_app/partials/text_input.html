Text Input

File: GalaxyTextInput.js
Tag: galaxy-text-input
Extends: GalaxyInputBase
A custom input element for text. It is a thin subclass of GalaxyInputBase -- it only sets its own type to "text" and adds no attributes or methods of its own, so its full API is documented on Input Base.

Attributes

None

No attributes of its own -- see Input Base for disabled, label, name, readonly, required, value, data-property, property-name, and placeholder.

Methods

None

No methods of its own -- see Input Base.

Duration Display

File: GalaxyDurationDisplay.js
Tag: galaxy-duration-display
Extends: GalaxyHTMLComponentBase
Renders a duration as read-only formatted text, showing only the configured visible units (visible-units). Any larger unit is absorbed into the highest visible unit (e.g. 2 days 3 hours, shown as hours/minutes, becomes "51h 0m"). The smallest visible unit's precision is controlled by precision-mode: "truncate" (drop anything finer), "round_up" (round up, cascading into larger units as needed), or "fraction" (show a decimal at fraction-digits places). format selects "short" ("2d 4h 12m") or "long" ("2 days, 4 hours, 12 minutes") rendering, each with correct singular/plural labels. Uses Duration Utils for all of its unit math.

Attributes

unit

Observed: true
Default: seconds
The unit the value attribute is expressed in. Falls back to seconds (with a console warning) if set to an unsupported unit.

visible-units

Observed: true
Default: ["days","hours","minutes","seconds"]
A JSON array naming which day/hour/minute/second units are shown.

format

Observed: true
Default: "short"
"short" ("2d 4h 12m") or "long" ("2 days, 4 hours, 12 minutes").

precision-mode

Observed: true
Default: "truncate"
How the smallest visible unit handles a remainder: "truncate", "round_up", or "fraction".

fraction-digits

Observed: true
Default: 0
Decimal places for the smallest unit when precision-mode is "fraction".

separator

Observed: true
Default: null (" " for short, ", " for long)
Text joining segments.

short-unit-labels

Observed: true
Default: DEFAULT_SHORT_UNIT_LABELS
A JSON object of abbreviations used in "short" format.

long-unit-labels

Observed: true
Default: DEFAULT_LONG_UNIT_LABELS
A JSON object of singular/plural labels ({singular, plural} per unit) used in "long" format.

value

Observed: true
Default: 0
The raw duration to display, expressed in unit. See value for the getter/setter's intentional asymmetry.

Methods

async attribute_changed_callback(name, old_value, new_value)

Re-renders the displayed text whenever any observed attribute changes.

render()

Re-renders the element's text from the current value/properties. Call this after changing multiple attributes at once -- attribute_changed_callback already calls it automatically for a single attribute change.

Getters / Setters

value

get: Returns the currently displayed formatted_text -- not the raw numeric value back.
set: Replaces the displayed duration with a new scalar value, expressed in unit, and re-renders. This getter/setter pair is intentionally asymmetric (matching the vanilla component it was ported from): writing sets the raw duration, reading returns the formatted string.

formatted_text

get: Builds the formatted duration text for the current value/properties.

safe_visible_unit_order

get: visible_units reduced to the canonical days-to-seconds rendering order, falling back to all four units (with a console warning) if the configured list is malformed, rather than letting a bad attribute value throw out of a lifecycle callback.

Observers

None

Handled by a single attribute_changed_callback() rather than per-attribute observer methods.

Example


            
            
        

            let display = document.querySelector('galaxy-duration-display');

            display.value = 120; // updates the raw duration and re-renders

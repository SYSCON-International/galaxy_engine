Button

File: GalaxyButton.js
Tag: galaxy-button
Extends: GalaxyComponentBase.js
The GalaxyButton component is a custom button element that extends the functionality of the base component. It allows for easy creation of buttons with customizable labels and click events.

Attributes

Methods

on_button_click()

Handles the built-in click event for the button. If the button has confirmation enabled, it will show a confirmation modal. It will also update the modal's title, body, and button texts based on the component's attributes.

on_confirm_modal_ok_button_click()

Handles the confirm modal button click event. Triggers the confirm callback if provided and closes the modal.

on_confirm_modal_cancel_button_click()

Handles the cancel button click event in the confirm modal. Triggers the cancel callback if provided and closes the modal.

Getters / Setters

textContent

get: Gets the text content of the button.
set: Sets the text content of the button to the specified value.

confirm_callback

get: Gets the callback function that is called when the ok button is clicked and confirmation is required.
set: Sets the callback function that is called when the ok button is clicked and confirmation is required.

cancel_callback

get: Gets the callback function that is called when the cancel button is clicked and confirmation is required.
set: Sets the callback function that is called when the cancel button is clicked and confirmation is required.

confirm_title_text

get: Gets the text of the confirmation modal's title element if confirmation is required.
set: Sets the text of the confirmation modal's title element if confirmation is required.

confirm_body_text

get: Gets the text of the confirmation modal's body element if confirmation is required.
set: Sets the text of the confirmation modal's body element if confirmation is required.

confirm_button_text

get: Gets the text of the confirmation modal's ok button if confirmation is required.
set: Sets the text of the confirmation modal's ok button if confirmation is required.

cancel_button_text

get: Gets the text of the confirmation modal's cancel button if confirmation is required.
set: Sets the text of the confirmation modal's cancel button if confirmation is required.

Observers

handle_observed_confirm_title_text(new_value)

Handles the confirm title attribute change. If no value is provided, it defaults to "Confirm".

handle_observed_confirm_body_text(new_value)

Handles the confirm body attribute change. If no value is provided, it defaults to "Are you sure?".

handle_observed_confirm_button_text(new_value)

Handles the confirm button text attribute change. If no value is provided, it defaults to "OK".

handle_observed_cancel_button_text(new_value)

Handles the cancel button text attribute change. If no value is provided, it defaults to "Cancel".

Example


            <galaxy-button has-confirmation>Ok</galaxy-button>;

Component Base

File: GalaxyComponentBase.js
Tag: N/A
Extends: HTMLElement

This is the base class for all Galaxy Engine components. It extends the native HTMLElement class giving access to lifecycle methods. It also provides additional functionality specific to Galaxy Engine components. The components base class is designed to be extended by other components, allowing them to inherit common functionality and structure.

The most important methods inherited from HTMLElement are connectedCallback(), disconnectedCallback(), and attributeChangedCallback(). These methods are called when the component is added to or removed from the DOM, and when an observed attribute is changed, respectively. Unlike HTMLElement, the component base class uses pre, current, and post methods for connectedCallback(), disconnectedCallback(), and attributeChangedCallback() allowing for more control over the component's lifecycle in inheritance chains. This pre, current, and post structure is also applied to the static getters for observedAttributes, allowing for more control over the order in which attributes are observed.

Attributes

Methods

async pre_attribute_changed_callback(name, old_value, new_value)

Web Components API - Lifecycle hook: called when an observed attribute changes. This method is called before attribute_changed_callback().

async attribute_changed_callback(name, old_value, new_value)

Web Components API - Lifecycle hook: called when an observed attribute changes. This method is called after pre_attribute_changed_callback() and before post_attribute_changed_callback().

async post_attribute_changed_callback(name, old_value, new_value)

Web Components API - Lifecycle hook: called when an observed attribute changes. This method is called after attribute_changed_callback().

async attributeChangedCallback(name, old_value, new_value)

Web Components API - Lifecycle hook: called when an observed attribute changes. When this method is called, it will call asynchronously pre_attribute_changed_callback(), attribute_changed_callback(), and post_attribute_changed_callback() in that order.

async pre_on_create()

Web Components API - Lifecycle hook: called as a part of connectedCallback() when the element is added to the DOM. This method is called before on_create().

async on_create()

Web Components API - Lifecycle hook: called as a part of connectedCallback() when the element is added to the DOM. This method is called after pre_on_create() and before post_on_create().

async post_on_create()

Web Components API - Lifecycle hook: called as a part of connectedCallback() when the element is added to the DOM. This method is called after on_create().

async connectedCallback()

Web Components API - Lifecycle hook: called when the element is added to the DOM. When this method is called, it will call asynchronously pre_on_create(), on_create(), and post_on_create() in that order.

async pre_on_destroy()

Web Components API - Lifecycle hook: called as a part of disconnectedCallback() when the element is removed from the DOM. This method is called before on_destroy().

async on_destroy()

Web Components API - Lifecycle hook: called as a part of disconnectedCallback() when the element is removed from the DOM. This method is called after pre_on_destroy() and before post_on_destroy().

async post_on_destroy()

Web Components API - Lifecycle hook: called as a part of disconnectedCallback() when the element is removed from the DOM. This method is called after on_destroy().

async disconnectedCallback()

Web Components API - Lifecycle hook: called when the element is removed from the DOM. When this method is called, it will call asynchronously pre_on_destroy(), on_destroy(), and post_on_destroy() in that order.

async get_template(template_html = null)

Returns the template HTML for the component. If template_html is provided, it will be used as the template. Otherwise, it will return the component_html_template property of the component.

Getters / Setters

pre_observed_attributes

Observed attributes that will trigger the attributeChangedCallback() These attributes will be added to the observedAttributes array before attributes in observed_attributes

get: Gets pre-observed attributes

observed_attributes

Observed attributes that will trigger the attributeChangedCallback() These attributes will be added to the observedAttributes array after attributes in pre_observed_attributes and before post_observed_attributes

get: Gets observed attributes

post_observed_attributes

Observed attributes that will trigger the attributeChangedCallback() These attributes will be added to the observedAttributes array after attributes in pre_observed_attributes and observed_attributes

get: Gets post-observed attributes

observedAttributes

The complete list of observed attributes that will trigger the attributeChangedCallback()

get: Gets the combined pre_observed_attributes, observed_attributes, and post_observed_attributes lists.
